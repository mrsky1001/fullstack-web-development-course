# Инструкция: Создание Auth Frontend на Svelte (Шаг за шагом)

Эта инструкция поможет вам создать современный фронтенд на Svelte с маршрутизацией, который работает с бэкендом на Passport.js.

## Предварительные требования
У вас должен быть запущен бэкенд на порту 3000 (папка `backend`).

---

## Шаг 1: Настройка Бэкенда (CORS)
Чтобы фронтенд мог общаться с бэкендом, нужно разрешить перекрестные запросы (CORS).

1. В папке бэкенда: `npm install cors`
2. В `src/app.js` добавьте:
```javascript
const cors = require('cors');
app.use(cors({
    origin: true, // Разрешить запросы с любого порта localhost
    credentials: true // Важно для пересылки сессионных куки
}));
```

---

## Шаг 2: Создание Svelte проекта
1. Создайте папку `frontend`.
2. В терминале (в этой папке):
   ```bash
   npm create vite@latest . -- --template svelte
   npm install
   npm install svelte-spa-router
   ```

---

## Шаг 3: Глобальное хранилище (Auth Store)
Создайте файл `src/lib/authStore.js`. Это сердце нашего приложения. Здесь мы храним данные пользователя и функции для API.

**Почему это важно?**
- Мы используем `writable` store, чтобы состояние пользователя было доступно в любом компоненте.
- Везде используем `credentials: 'include'` в fetch — без этого браузер не будет сохранять сессию.

---

## Шаг 4: Маршрутизация (Routing)
В Svelte (без SvelteKit) мы используем `svelte-spa-router`.

1. Создайте папку `src/routes/`.
2. Создайте компоненты: `Home.svelte`, `Login.svelte`, `Register.svelte`, `Profile.svelte`.
3. В `App.svelte` настройте роутер:
```svelte
<script>
    import Router from 'svelte-spa-router';
    import Home from './routes/Home.svelte';
    // ... импорт других страниц
    const routes = { '/': Home, '/login': Login, ... };
</script>
<Router {routes} />
```

---

## Шаг 5: Сохранение авторизации после перезагрузки
Это самая важная часть. Чтобы авторизация не "слетала":

1. В `App.svelte` в блоке `onMount` вызывайте `auth.check()`.
2. Эта функция делает запрос к бэкенду на `/auth/check`.
3. Если пользователь авторизован — бэкенд узнает его по кукам и вернет данные. Мы записываем их в Store.

---

## Шаг 6: Защита страниц (Guard)
В компоненте `Profile.svelte`:
1. В `onMount` проверяем: если пользователя нет в Store и загрузка завершена — перенаправляем на `#/login`.

---

## Как запустить?
1. Бэкенд: `npm run start` (порт 3000)
2. Фронтенд: `npm run dev` (порт 5173 или любой другой)
3. Откройте адрес фронтенда в браузере.

**Готово! Теперь у вас есть полноценное SPA приложение с авторизацией.**
