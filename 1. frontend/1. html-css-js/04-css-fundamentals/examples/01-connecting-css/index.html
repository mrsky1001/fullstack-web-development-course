Три способа подключения CSS

1. Инлайн стили (inline)

Этот текст стилизован инлайн (атрибут style) 

<p style="color: red; font-size: 18px;">Текст</p>

⚠️ Не рекомендуется! Сложно поддерживать.

2. Внешний CSS (external)

Этот текст стилизован из внешнего файла external.css 

<link rel="stylesheet" href="external.css">

✅ Рекомендуется! Кэшируется, переиспользуется.

3. Внутренний CSS (internal)

Этот текст стилизован из тега <style> в head 

<style> .class { color: red; } </style>

⚡ Иногда используется для критичных стилей.

Сравнение способов

Способ Кэширование Переиспользование Приоритет
Inline ❌ Нет ❌ Нет 🔺 Высший
Internal ❌ Нет ❌ Нет Средний
External ✅ Да ✅ Да Средний
