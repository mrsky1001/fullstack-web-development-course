# Глава 0. Введение: как читать техническое задание

## 🎯 Задание

Научиться читать и понимать техническое задание (ТЗ). Разобрать ТЗ проекта TechParts, выделить ключевые требования и составить план работы.

## 📚 Теория

### Что такое ТЗ?

**Техническое задание** — это документ, в котором написано, ЧТО нужно сделать и КАК это будет оцениваться.

> **Аналогия из жизни:** ТЗ — это рецепт блюда. В нём написано, какие ингредиенты нужны, в каком порядке их смешивать и как должен выглядеть результат. Если следовать рецепту — получится вкусно. Если импровизировать — может получиться, а может нет.

### Три части веб-приложения

Наш проект состоит из трёх частей, которые работают вместе:

```
🖥️ Frontend         ⚙️ Backend           🗄️ База данных
(клиент)             (сервер)              (хранилище)
─────────            ─────────             ─────────
HTML, CSS, JS        Node.js + Express     MySQL
Что видит            Обрабатывает          Хранит всю
пользователь         запросы               информацию
```

> **Аналогия:** Представьте ресторан.
> - **Frontend** — это зал ресторана: меню, столики, официант принимает заказ
> - **Backend** — это кухня: повар получает заказ и готовит блюдо
> - **База данных** — это склад: здесь хранятся все продукты

### Как это работает вместе?

```
Пользователь         JavaScript          Сервер            MySQL
нажимает    ──────►  отправляет  ──────►  обращается  ──────►  возвращает
кнопку               запрос (fetch)       к БД               данные
                                                            ◄──────
                     обновляет  ◄──────  формирует   ◄──────
                     страницу            ответ (JSON)
```

### Критерии оценивания

Наш проект оценивается по **21 критерию** на **100 баллов**. Каждый критерий — это конкретная задача. Например:

| № | Что делаем | Баллы |
|---|-----------|-------|
| 1 | Используем весь стек технологий | 5 |
| 6 | Подбираем цвета, шрифты, стилизуем картинки | 6 |
| 14 | Делаем слайдер с автопереключением | 3 |
| 16 | Создаём форму регистрации с валидацией | 10 |
| 21 | Создаём базу данных с 3 таблицами | 18 |

## 🔍 Примеры

### Разбор одного требования из ТЗ

Возьмём из ТЗ: *«Слайдер с 4 изображениями 800×400, автопереключение каждые 3 секунды»*

Разложим на составляющие:
- **Что:** слайдер — блок, где картинки сменяют друг друга
- **Сколько:** 4 изображения
- **Размер:** 800×400 пикселей
- **Поведение:** меняется автоматически каждые 3 секунды
- **Дополнительно:** кнопки «Вперёд»/«Назад» + точки-индикаторы

### Наш порядок работы

```
Шаг 1 → Структура папок и файлов
Шаг 2 → База данных (таблицы + начальные данные)
Шаг 3 → HTML-разметка всех страниц
Шаг 4 → CSS-стилизация
Шаг 5 → JavaScript (слайдер, валидация форм)
Шаг 6 → Backend (сервер + API)
Шаг 7 → Интеграция (всё вместе)
```

# Глава 0.5. Инструменты разработчика: установка и настройка

## 📚 Теория

### Зачем столько программ?

> **Аналогия:** Чтобы построить дом, нужны разные инструменты: молоток, дрель, уровень, рулетка. Каждый делает своё дело. Программист тоже использует набор инструментов — это называется **стек технологий**.

Вот наш «набор инструментов»:

```
🔧 Наш стек технологий:

🗄️ MySQL Server           — хранит данные (база данных)
🔍 MySQL Workbench        — визуальный интерфейс для работы с базой
```

### 2. 🌐 Браузер: Google Chrome

Нам нужен современный браузер с **инструментами разработчика** (DevTools). Google Chrome — стандарт индустрии.

| | |
|---|---|
| **Сайт** | https://www.google.com/chrome |
| **Цена** | Бесплатный |

| Вкладка | Для чего |

### 3. 🟢 Node.js (среда для запуска серверного JavaScript)

**Node.js** позволяет запускать JavaScript не только в браузере, но и на вашем компьютере — как обычную программу. Без него наш сервер (backend) не заработает.

> **Аналогия:** JavaScript в браузере — это повар, который готовит только в зале ресторана (на глазах у клиентов). Node.js — это возможность перевести повара **на кухню**, где он может делать гораздо больше: работать с файлами, базой данных, обрабатывать запросы.

| | |
|---|---|
| **Сайт** | https://nodejs.org |
| **Цена** | Бесплатный |
| **Версия** | Скачивайте **LTS** (Long Term Support) — это стабильная версия |

**Установка:**
1. Перейдите на https://nodejs.org
2. Нажмите зелёную кнопку **LTS** (НЕ «Current»!)
3. Запустите скачанный установщик
4. На всех шагах нажимайте **Next**, ничего не меняя
5. **Важно:** на этапе «Tools for Native Modules» поставьте галочку, если предлагается

**Проверка установки:**

Откройте терминал (в VS Code: `Ctrl + ~`, или найдите «cmd» / «PowerShell» в меню Пуск) и введите:

```bash
node --version
```
Должно вывести что-то вроде: `v20.11.0` (номер версии может отличаться)

```bash
npm --version
```
Должно вывести: `10.2.4` (или другой номер)

**Что устанавливается вместе с Node.js:**
- **node** — сам интерпретатор JavaScript
- **npm** (Node Package Manager) — менеджер пакетов. Аналогия: это «магазин приложений» для JavaScript. Через npm мы скачаем Express, mysql2 и другие библиотеки

> **⚠️ Частая ошибка:** «node не является внутренней или внешней командой» — означает, что Node.js не добавился в PATH. Переустановите Node.js и убедитесь, что на шаге установки стоит галочка «Add to PATH».

### 4. 🗄️ MySQL Server (сервер базы данных)

**MySQL Server** — программа, которая хранит данные и обрабатывает SQL-запросы. Она работает «в фоне» на вашем компьютере.

> **Аналогия:** MySQL Server — это **склад с кладовщиком**. Кладовщик принимает записки («Дай товар №5», «Добавь нового пользователя») и выполняет их. Работает тихо, в фоне — вы его не видите.

| | |
|---|---|
| **Сайт** | https://dev.mysql.com/downloads/mysql |
| **Цена** | Бесплатный (Community Edition) |

**Установка (Windows):**
1. Перейдите на https://dev.mysql.com/downloads/installer
2. Скачайте **MySQL Installer for Windows** (файл `mysql-installer-community-*.msi`)
3. Нажмите «No thanks, just start my download» (регистрация не обязательна)
4. Запустите установщик
5. Выберите **«Developer Default»** — установит и Server, и Workbench
6. На этапе **«Accounts and Roles»**:
   - Задайте пароль для пользователя `root` (например: `admin` или `12345678`)
   - ⚠️ **ЗАПОМНИТЕ ЭТОТ ПАРОЛЬ!** Он понадобится для подключения из кода
7. Нажимайте **Next → Execute → Finish**

**Проверка:**
```bash
mysql --version
```
Должно вывести: `mysql Ver 8.0.XX...`

> **⚠️ Частая ошибка:** «mysql не является командой» — добавьте путь к MySQL в переменную PATH. Обычно это `C:\Program Files\MySQL\MySQL Server 8.0\bin`. Или используйте MySQL Workbench вместо командной строки.

### 5. 🔍 MySQL Workbench (визуальный интерфейс для MySQL)

**MySQL Workbench** — графическая программа для работы с базой данных. Вместо того чтобы писать команды в командной строке, вы видите таблицы, данные и связи в удобном интерфейсе.

> **Аналогия:** Если MySQL Server — это склад, то Workbench — это **планшет кладовщика** с красивым интерфейсом. Удобнее, чем записки от руки.

| | |
|---|---|
| **Сайт** | https://dev.mysql.com/downloads/workbench |
| **Цена** | Бесплатный |

**Установка:**
- Если вы выбрали «Developer Default» при установке MySQL Server — Workbench уже установлен!
- Если нет — скачайте отдельно с https://dev.mysql.com/downloads/workbench

**Первое подключение:**
1. Запустите MySQL Workbench
2. На главном экране нажмите на **«Local instance MySQL80»** (или аналогичную карточку)
3. Введите пароль, который задавали при установке MySQL Server
4. Готово! Вы увидите окно для написания SQL-запросов

**Как выполнить SQL-файл (schema.sql или seed.sql):**
1. **File → Open SQL Script** → выберите файл `schema.sql`
2. Нажмите кнопку ⚡ **(Execute)** — жёлтая молния на панели инструментов
3. Внизу в панели «Output» появится результат: зелёная галочка = успех

**Как создать ER-диаграмму (Критерий №21: 2 балла):**
1. **Database → Reverse Engineer**
2. Подключитесь к серверу (введите пароль)
3. Выберите базу данных `techparts`
4. Нажмите **Next → Next → Execute → Next → Finish**
5. Появится визуальная схема с тремя таблицами и связями между ними
6. **File → Export → Export as PNG** → сохраните как `database/er-diagram.png`

# Глава 1. Структура проекта

## 🎯 Задание

Создать все папки и пустые файлы проекта согласно структуре из ТЗ. *(Критерий №3 — 2 балла)*

## 📚 Теория

### Зачем нужна структура?

> **Аналогия:** Представьте шкаф. Если вы кладёте все вещи в одну кучу — ничего не найдёте. Но если разложить по полкам (футболки, штаны, носки) — всё под рукой.

Так и в проекте:
- **`frontend/`** — всё, что видит пользователь (HTML, CSS, JS, картинки)
- **`backend/`** — «невидимая» серверная часть
- **`database/`** — файлы для базы данных

### Зачем разделять на подпапки?

Внутри `frontend/` мы не сваливаем всё в кучу, а делим:
- **`css/`** — стили отдельно от HTML (удобнее редактировать)
- **`js/`** — скрипты отдельно (один файл — одна задача)
- **`images/`** — картинки отдельно (не мешают коду)

Внутри `backend/` та же логика:
- **`config/`** — настройки (подключение к БД)
- **`controllers/`** — логика (что делать с данными)
- **`routes/`** — маршруты (какой URL вызывает какую логику)
- **`middleware/`** — промежуточные проверки (например, авторизован ли пользователь)

# Глава 2. База данных MySQL

## 🎯 Задание

Создать базу данных `techparts` с тремя таблицами: `users`, `products`, `orders`. Заполнить таблицу `products` начальными данными (минимум 4 товара). *(Критерий №21 — до 18 баллов)*

## 📚 Теория

### Что такое база данных?

> **Аналогия:** База данных — это огромная электронная таблица (как Excel). Но в отличие от Excel, она «умная» — сама следит за связями между данными и не даёт записать ерунду.

### Основные понятия

| Термин | Что это | Аналогия |
|--------|---------|----------|
| **Таблица** | Одна «страница» в базе | Лист в Excel |
| **Строка (запись)** | Один элемент данных | Одна строка в Excel |
| **Столбец (поле)** | Одна характеристика | Колонка в Excel |
| **PRIMARY KEY** | Уникальный номер записи | Номер паспорта |
| **AUTO_INCREMENT** | Автоматическая нумерация | Автоматический счётчик |
| **FOREIGN KEY** | Ссылка на запись в другой таблице | «Смотри запись №5 в таблице users» |
| **NOT NULL** | Поле обязательно для заполнения | Без имени анкету не примут |
| **UNIQUE** | Значение не может повторяться | Два человека с одинаковым паспортом — ошибка |

### Типы данных

| Тип | Для чего | Пример |
|-----|---------|--------|
| `INT` | Целые числа | 1, 42, 1000 |
| `VARCHAR(100)` | Текст до N символов | «Иванов Иван» |
| `TEXT` | Длинный текст | Описание товара |
| `DECIMAL(10,2)` | Деньги (10 цифр, 2 после запятой) | 38990.00 |
| `DATE` | Дата | 2024-12-25 |
| `DATETIME` | Дата и время | 2024-12-25 14:30:00 |

### Что такое внешний ключ (FOREIGN KEY)?

> **Аналогия:** Представьте заказ в ресторане. В заказе написан **номер столика** (а не имя клиента целиком). По номеру столика всегда можно найти, кто заказал.

Так же и в нашей базе:
- В таблице `orders` хранится `user_id` — это **номер** пользователя из таблицы `users`
- Если пользователь с id=5 сделал заказ, в заказе будет записано `user_id = 5`

### Что такое ON DELETE CASCADE?

> **Аналогия:** Если клиент ушёл из ресторана (удалили из `users`), все его заказы автоматически тоже убираются.

### Кодировка UTF-8

Чтобы база данных правильно хранила русские буквы (кириллицу), нужно указать кодировку `utf8mb4`.

## 🔍 Примеры

### Пример: создание простой таблицы

```sql
-- Создаём таблицу учеников
CREATE TABLE students (
  id   INT PRIMARY KEY AUTO_INCREMENT,  -- уникальный номер (авто)
  name VARCHAR(100) NOT NULL,            -- имя (обязательное)
  age  INT                               -- возраст (необязательное)
);
```

### Пример: добавление записи

```sql
-- Добавляем ученика (id подставится автоматически: 1, 2, 3...)
INSERT INTO students (name, age) VALUES ('Иван Иванов', 16);
INSERT INTO students (name, age) VALUES ('Мария Петрова', 15);
```

### Пример: внешний ключ

```sql
-- Таблица оценок (ссылается на таблицу students)
CREATE TABLE grades (
  id         INT PRIMARY KEY AUTO_INCREMENT,
  student_id INT NOT NULL,
  subject    VARCHAR(50),
  grade      INT,
  FOREIGN KEY (student_id) REFERENCES students(id) ON DELETE CASCADE
);

-- Ставим оценку ученику с id=1 (Иван Иванов)
INSERT INTO grades (student_id, subject, grade) VALUES (1, 'Математика', 5);
```

Откройте MySQL Workbench (или терминал MySQL) и создайте файл `database/schema.sql`:

```sql

-- Критерий №21: База данных (до 18 баллов)
-- ============================================================

  CHARACTER SET utf8mb4

```

**Разбор:**
- `CREATE DATABASE IF NOT EXISTS` — создать базу, если она ещё не существует
- `techparts` — имя базы из ТЗ
- `CHARACTER SET utf8mb4` — кодировка для русских букв
- `COLLATE utf8mb4_unicode_ci` — правила сравнения текста (регистронезависимое)
- `USE techparts;` — переключаемся на эту базу

### Шаг 2: Создаём таблицу users

```sql
-- ============================================================
-- Таблица users — информация о зарегистрированных пользователях
-- 5 баллов за корректную таблицу users
-- ============================================================
CREATE TABLE IF NOT EXISTS users (
  id         INT            PRIMARY KEY AUTO_INCREMENT,  -- Первичный ключ с автоинкрементом
  login      VARCHAR(50)    NOT NULL UNIQUE,              -- Логин (уникальный, обязательный)
  password   VARCHAR(255)   NOT NULL,                     -- Хешированный пароль (bcryptjs)
  fullname   VARCHAR(150)   NOT NULL,                     -- ФИО (обязательное)
  email      VARCHAR(100)   NOT NULL,                     -- Email (обязательный)
  phone      VARCHAR(20)    NOT NULL,                     -- Телефон (обязательный)
  created_at DATETIME       DEFAULT CURRENT_TIMESTAMP     -- Автоматическая фиксация даты
);
```

**Разбор каждого поля:**
- `id INT PRIMARY KEY AUTO_INCREMENT` — уникальный номер пользователя. Первый будет 1, второй — 2 и т.д.
- `login VARCHAR(50) NOT NULL UNIQUE` — логин. `NOT NULL` = обязательно, `UNIQUE` = не может повторяться
- `password VARCHAR(255)` — пароль. Почему 255 символов, если пароль короткий? Потому что мы храним не сам пароль, а его **хеш** (зашифрованную версию), а хеш всегда длинный
- `created_at DATETIME DEFAULT CURRENT_TIMESTAMP` — дата регистрации. `DEFAULT CURRENT_TIMESTAMP` означает «автоматически подставить текущую дату и время»

### Шаг 3: Создаём таблицу products

```sql
-- ============================================================
-- Таблица products — информация о доступных комплектующих
-- 5 баллов за корректную таблицу products
-- ============================================================
CREATE TABLE IF NOT EXISTS products (
  id          INT            PRIMARY KEY AUTO_INCREMENT,  -- Первичный ключ с автоинкрементом
  name        VARCHAR(200)   NOT NULL,                     -- Название товара
  description TEXT           NOT NULL,                     -- Описание товара
  price       DECIMAL(10,2)  NOT NULL,                     -- Цена в формате DECIMAL(10,2)
  category    VARCHAR(100)   NOT NULL,                     -- Категория товара (текстовое поле)
  image       VARCHAR(255)   DEFAULT 'images/default.jpg', -- Путь к изображению
  created_at  DATETIME       DEFAULT CURRENT_TIMESTAMP     -- Дата создания записи
);
```

**Разбор:**
- `price DECIMAL(10,2)` — почему не просто `INT`? Потому что цена может быть с копейками: `38990.50`. `DECIMAL(10,2)` означает «до 10 цифр всего, 2 после запятой»
- `description TEXT` — `TEXT` вместо `VARCHAR`, потому что описание может быть длинным (до 65000 символов)
- `category VARCHAR(100)` — категория нужна для фильтрации (процессоры, видеокарты и т.д.)

### Шаг 4: Создаём таблицу orders

```sql
-- ============================================================
-- Таблица orders — связывает пользователей с заказанными товарами
-- 5 баллов за корректную таблицу orders
-- ============================================================
CREATE TABLE IF NOT EXISTS orders (
  id            INT            PRIMARY KEY AUTO_INCREMENT,
  user_id       INT            NOT NULL,                     -- Внешний ключ на users
  product_id    INT            NOT NULL,                     -- Внешний ключ на products
  delivery_date DATE           NOT NULL,                     -- Дата доставки
  quantity      INT            NOT NULL,                     -- Количество единиц (1-10)
  total_price   DECIMAL(10,2)  NOT NULL,                     -- Общая стоимость
  comment       TEXT           DEFAULT NULL,                  -- Комментарий (необязательно)
  created_at    DATETIME       DEFAULT CURRENT_TIMESTAMP,

  -- Два внешних ключа с каскадным удалением
  FOREIGN KEY (user_id)    REFERENCES users(id)    ON DELETE CASCADE,
  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
);
```

**Разбор:**
- `user_id INT NOT NULL` — ссылка на пользователя, который сделал заказ
- `product_id INT NOT NULL` — ссылка на заказанный товар
- `FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE` — если удалить пользователя, все его заказы автоматически удалятся
- `comment TEXT DEFAULT NULL` — необязательное поле. `DEFAULT NULL` означает «если не указано — будет пустым»

# Глава 3. Главная страница: HTML-каркас

## 🎯 Задание

Создать HTML-разметку главной страницы `index.html` с шапкой (логотип + меню), слайдером, секцией «Популярные товары» и подвалом. *(Критерии №4, №5, №7, №10, №11, №12)*

## 📚 Теория

### Что такое HTML?

> **Аналогия:** HTML — это **скелет** человека. Он определяет, из каких частей состоит страница (голова, тело, руки, ноги), но не определяет, как они выглядят. Внешний вид — это CSS (одежда).

HTML-документ состоит из **тегов** — команд в угловых скобках:

```html
<тег>содержимое</тег>
```

### Структура HTML-документа

Каждый HTML-документ начинается одинаково:

```html
<!DOCTYPE html>        <!-- Говорим браузеру: «Это HTML5» -->
<html lang="ru">       <!-- Начало документа, язык — русский -->
<head>                 <!-- Голова: невидимые настройки -->
  <meta charset="UTF-8">          <!-- Кодировка для русских букв -->
  <title>Заголовок вкладки</title> <!-- Текст на вкладке браузера -->
  <link rel="stylesheet" href="css/style.css"> <!-- Подключаем CSS -->
</head>
<body>                 <!-- Тело: всё, что видит пользователь -->
  ...содержимое...
</body>
</html>
```

### Семантические теги

**Семантические теги** — теги с «говорящими» именами. Они делают то же, что `<div>`, но браузер и поисковые системы **понимают**, что внутри.

| Тег | Что означает | Аналогия |
|-----|-------------|----------|
| `<header>` | Шапка страницы | Вывеска магазина |
| `<nav>` | Навигационное меню | Указатели в ТЦ |
| `<main>` | Основной контент | Торговый зал |
| `<section>` | Раздел внутри main | Отдел магазина |
| `<footer>` | Подвал | Информация мелким шрифтом |

### SVG-логотип

SVG — это **векторное** изображение. В отличие от JPG/PNG, оно не теряет качество при увеличении, потому что хранится как набор математических формул, а не пикселей.

## 🔍 Примеры

### Минимальная HTML-страница

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая веб-страница.</p>
</body>
</html>
```

### Семантическая разметка vs «div-суп»

```html
<!-- ❌ Плохо: «div-суп» — непонятно, что где -->
<div class="top">
  <div class="menu">...</div>
</div>
<div class="content">...</div>
<div class="bottom">...</div>

<!-- ✅ Хорошо: семантические теги — всё понятно -->
<header>
  <nav>...</nav>
</header>
<main>...</main>
<footer>...</footer>
```

## 📚 Теория

### Что такое CSS?

> **Аналогия:** Если HTML — это скелет, то CSS — это **одежда, макияж и причёска**. CSS определяет, как всё выглядит: цвета, размеры, расположение элементов.

### CSS-переменные

CSS-переменные — это «настройки» в одном месте. Меняешь одну строку — и цвет меняется на всём сайте.

> **Аналогия:** Вместо того чтобы перекрашивать каждую стену вручную, вы меняете одну банку краски — и весь дом перекрашивается.

```css
:root {
  --primary: #2563eb;  /* Задаём переменную */
}
.button {
  background: var(--primary);  /* Используем */
}
```

### Flexbox и Grid

| Инструмент | Для чего | Аналогия |
|-----------|---------|----------|
| **Flexbox** | Расположить элементы в ряд или столбец | Поставить солдатиков в шеренгу |
| **CSS Grid** | Разложить элементы в сетку | Разложить книги на полке: по 3 штуки в ряд |

### object-fit: cover

Если вставить картинку в блок другого размера, она может растянуться и исказиться. Свойство `object-fit: cover` растягивает картинку **без искажения**, обрезая лишнее.

> **Аналогия:** Вы обрезаете фотографию так, чтобы она идеально заполнила рамку — не растягиваясь, а просто обрезая края.

## 🔍 Примеры

### Flexbox — 3 блока в ряд:
```css
.container {
  display: flex;
  justify-content: space-between; /* Равномерно распределить */
  gap: 20px;                      /* Отступ между элементами */
}
```

### Grid — сетка 3 колонки:
```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 равные колонки */
  gap: 25px;
}
```

### Плавный переход при наведении:
```css
.card {
  transition: transform 0.2s;     /* Плавность */
}
.card:hover {
  transform: translateY(-4px);    /* Поднимается вверх на 4px */
}
```

# Глава 5. JavaScript: слайдер и динамическое меню

## 🎯 Задание

Создать слайдер с автопереключением каждые 3 секунды, кнопками «Вперёд»/«Назад» и индикаторами-точками. *(Критерий №14 — до 3 баллов)*

## 📚 Теория

### Что такое JavaScript?

> **Аналогия:** HTML — скелет, CSS — одежда, а JavaScript — это **мозг**. Он делает страницу «живой»: кнопки начинают работать, картинки переключаются, формы проверяются.

### Основные концепции

| Что | Как работает | Аналогия |
|-----|-------------|----------|
| `document.getElementById('id')` | Найти элемент на странице по его id | Найти книгу по номеру на полке |
| `querySelectorAll('.класс')` | Найти все элементы с данным классом | Найти все красные книги |
| `classList.add('active')` | Добавить CSS-класс элементу | Надеть бейджик «активный» |
| `classList.remove('active')` | Убрать CSS-класс | Снять бейджик |
| `addEventListener('click', fn)` | Выполнить функцию при клике | Поставить охранника: «когда кто-то нажмёт — сделай это» |
| `setInterval(fn, 3000)` | Повторять функцию каждые 3000 мс | Будильник каждые 3 секунды |

## 🔍 Примеры

### Минимальный пример: кнопка меняет текст

```html
<p id="text">Привет!</p>
<button id="btn">Нажми</button>

<script>
  document.getElementById('btn').addEventListener('click', () => {
    document.getElementById('text').textContent = 'Кнопка нажата!';
  });
</script>
```

### setInterval — действие каждую секунду

```javascript
let count = 0;
setInterval(() => {
  count++;
  console.log('Прошло секунд: ' + count);
}, 1000);
```

## 🛠️ Реализация

### Файл `js/slider.js`

```javascript
// ============================================================
// TechParts — Слайдер на главной странице (slider.js)
// Критерий №14: Блок со слайдером (до 3 баллов)
// ============================================================

// --- Получаем элементы слайдера из DOM ---
const slides = document.querySelectorAll('.slider-slide');  // Все слайды
const dots = document.querySelectorAll('.slider-dot');      // Точки-индикаторы
const prevBtn = document.getElementById('slider-prev');     // Кнопка «Назад»
const nextBtn = document.getElementById('slider-next');     // Кнопка «Вперёд»

// Текущий индекс слайда (начинаем с 0)
let currentSlide = 0;

// --- Функция: показать слайд по индексу ---
function showSlide(index) {
  // Убираем класс active у всех слайдов и точек
  slides.forEach(slide => slide.classList.remove('active'));
  dots.forEach(dot => dot.classList.remove('active'));

  // Зацикливание: если дошли до конца — возвращаемся в начало
  currentSlide = (index + slides.length) % slides.length;

  // Добавляем active текущему слайду и точке
  slides[currentSlide].classList.add('active');
  dots[currentSlide].classList.add('active');
}

// --- Кнопка «Вперёд» ---
nextBtn.addEventListener('click', () => showSlide(currentSlide + 1));

// --- Кнопка «Назад» ---
prevBtn.addEventListener('click', () => showSlide(currentSlide - 1));

// --- Клик по точке-индикатору ---
dots.forEach(dot => {
  dot.addEventListener('click', () => {
    const index = parseInt(dot.getAttribute('data-index'));
    showSlide(index);
  });
});

// --- Автоматическое переключение каждые 3 секунды ---
setInterval(() => showSlide(currentSlide + 1), 3000);
```

**Как работает зацикливание?**
```
slides.length = 4 (слайды 0, 1, 2, 3)

Вперёд от слайда 3: (3 + 1 + 4) % 4 = 8 % 4 = 0 → вернулись в начало!
Назад от слайда 0:  (0 - 1 + 4) % 4 = 3 % 4 = 3 → перешли в конец!
```

> **⚠️ Частая ошибка:** «Cannot read property of null» → скрипт подключён в `<head>`, а элементы ещё не загрузились. Подключайте скрипты перед `</body>`!

# Глава 6. Формы: регистрация и авторизация

## 🎯 Задание

Создать формы регистрации (6 полей с валидацией) и авторизации (2 поля). *(Критерии №8, №16 — до 10 баллов, №17 — до 4 баллов)*

## 📚 Теория

### Что такое HTML-форма?

> **Аналогия:** Форма — это **анкета**. У каждого поля есть подпись (label), подсказка (placeholder) и правила (обязательное / необязательное, минимальная длина).

### Ключевые атрибуты полей ввода

| Атрибут | Что делает | Пример |
|---------|-----------|--------|
| `type="text"` | Обычное текстовое поле | Логин |
| `type="password"` | Скрывает символы точками | Пароль |
| `type="email"` | Подсказывает формат email | user@mail.ru |
| `type="tel"` | Подсказывает формат телефона | +7... |
| `required` | Поле обязательно | Форма не отправится, если пусто |
| `minlength="8"` | Минимальная длина | Пароль ≥ 8 символов |
| `placeholder="..."` | Подсказка внутри поля | Серый текст |

### Валидация — что это?

**Валидация** — проверка данных перед отправкой.

> **Аналогия:** Охранник на входе проверяет пропуск. Если пропуск неправильный — не пускает и объясняет, что не так.

Валидация бывает двух видов:
1. **Клиентская** (JavaScript) — мгновенная проверка в браузере, ещё до отправки
2. **Серверная** (Node.js) — дополнительная проверка на сервере. Клиентскую можно обойти (отключив JS), а серверную — нет

### Регулярные выражения

**Регулярное выражение (RegExp)** — шаблон для проверки текста.

```javascript
/^[A-Za-z0-9]+$/.test('user123')  // true — только буквы и цифры
/^[A-Za-z0-9]+$/.test('user 123') // false — пробел не допускается
```

```javascript
// ============================================================
// TechParts — Регистрация и авторизация (auth.js)
// Критерий №16: Регистрация (до 10 баллов)
// ============================================================

const API = 'http://localhost:3000/api';
const registerForm = document.getElementById('register-form');

// --- Маска телефона: +7 (XXX) XXX-XX-XX ---
const phoneInput = document.getElementById('phone');
if (phoneInput) {

    let digits = value.replace(/\D/g, '');  // Оставляем только цифры

    if (!digits.startsWith('7') && digits.length > 0) digits = '7' + digits;

    if (digits.length > 0) result = '+' + digits[0];
    if (digits.length > 1) result += ' (' + digits.slice(1, 4);

    if (digits.length > 4) result += digits.slice(4, 7);

    if (digits.length > 9) result += '-' + digits.slice(9, 11);
    return result;
  }

    phoneInput.value = formatPhone(phoneInput.value);
  });

    if (!phoneInput.value) phoneInput.value = '+7';

    const fullname = document.getElementById('fullname').value.trim();
    const email = document.getElementById('email').value.trim();
    const phone = document.getElementById('phone').value.trim();

    let hasError = false;

    // 1) Логин: латинские буквы и цифры, минимум 5 символов
    if (login.length < 5 || !/^[A-Za-z0-9]+$/.test(login)) {
      showFieldError('login', 'Только латинские буквы и цифры, мин. 5 символов');
      hasError = true;
    }

    // 2) Пароль: минимум 8 символов
    if (password.length < 8) {
      showFieldError('password', 'Минимум 8 символов');
      hasError = true;
    }

    // 3) Совпадение паролей
    if (password !== password2) {
      showFieldError('password2', 'Пароли не совпадают');
      hasError = true;
    }

    // 4) ФИО: минимум 3 слова
    if (fullname.split(/\s+/).filter(w => w.length > 0).length < 3) {
      showFieldError('fullname', 'Введите полное ФИО (минимум 3 слова)');
      hasError = true;
    }

    // 5) Email: содержит @ и .
    if (!email.includes('@') || !email.includes('.')) {
      showFieldError('email', 'Введите корректный email');
      hasError = true;
    }

    // 6) Телефон: формат +7 (XXX) XXX-XX-XX
    if (!/^\+7\s?\(\d{3}\)\s?\d{3}-\d{2}-\d{2}$/.test(phone)) {
      showFieldError('phone', 'Формат: +7 (XXX) XXX-XX-XX');
      hasError = true;
    }

    if (hasError) return;

    // Отправляем данные на сервер
    try {
      const res = await fetch(API + '/auth/register', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        credentials: 'include',
        body: JSON.stringify({ login, password, fullname, email, phone })
      });
      const data = await res.json();

      if (res.ok) {
        document.getElementById('register-message').innerHTML =
          '<div class="message success">Регистрация успешна! <a href="login.html">Войти</a></div>';
      } else {
        document.getElementById('register-message').innerHTML =
          `<div class="message error">${data.error}</div>`;
      }
    } catch (err) {
      console.error('Ошибка:', err);
    }
  });
}

// --- Функция показа ошибки у поля ---
function showFieldError(fieldId, message) {
  const input = document.getElementById(fieldId);
  const errorDiv = document.getElementById(fieldId + '-error');
  if (input) input.classList.add('error');
  if (errorDiv) errorDiv.textContent = message;
  if (input) {
    input.addEventListener('input', () => {
      input.classList.remove('error');
      if (errorDiv) errorDiv.textContent = '';
    }, { once: true });
  }
}
```

# Глава 8. Backend: сервер Node.js + Express

## 🎯 Задание

Создать серверную часть: Express-сервер, подключение к MySQL, API для авторизации, товаров и заказов. *(Критерии №1, №2, №13)*

## 📚 Теория

### Что такое Node.js?

> **Аналогия:** JavaScript обычно работает только в браузере. Node.js позволяет запускать JavaScript **на компьютере** — как обычную программу. Это и есть наш сервер.

### Что такое Express?

> **Аналогия:** Если Node.js — это кухня, то Express — это набор готовой посуды и инструментов. Без него можно готовить, но с ним — гораздо быстрее.

### MVC-архитектура

```
Запрос от браузера
     ↓
📬 Routes (маршрутизатор)     — «Какой запрос пришёл? Кому передать?»
     ↓
🛡️ Middleware (охранник)      — «Пользователь авторизован?»
     ↓
🧠 Controller (контроллер)    — «Что делать с данными?» → запрос к БД
     ↓
📦 Ответ (JSON)               — отправляется обратно в браузер
```

### Сессии

> **Аналогия:** Сессия — это **браслет в аквапарке**. При входе (авторизации) вам надевают браслет. По нему система видит, что вы заплатили. При выходе (logout) браслет снимается.

Технически: при авторизации сервер создаёт запись `req.session.user_id = 5`. При каждом следующем запросе браузер отправляет cookie, а сервер по ней находит сессию и понимает, кто обратился.

### bcryptjs — хеширование паролей

> **Аналогия:** Вы кладёте записку в сейф. Прочитать её невозможно, но можно проверить: «Совпадает ли новая записка с той, что в сейфе?»

```javascript
// Хешируем пароль (при регистрации)
const hash = await bcrypt.hash('MyPassword123', 10);
// hash = "$2a$10$xK8j..." — длинная зашифрованная строка

// Проверяем пароль (при авторизации)
const match = await bcrypt.compare('MyPassword123', hash);
// match = true — пароли совпадают!
```
