# Шаг за шагом: Вебинар 6 — Формы и валидация

## О чём этот раздел?

В этом вебинаре мы учимся работать с формами: перехватывать событие `submit`, отменять стандартную перезагрузку страницы через `event.preventDefault()`, проверять введённые данные (`.trim()`, совпадение паролей) и сохранять авторизацию пользователя в `localStorage`.

В каждой папке шага — плоская структура файлов:
- `index.html`
- `style.css`
- `main.js`
- `README.md`
