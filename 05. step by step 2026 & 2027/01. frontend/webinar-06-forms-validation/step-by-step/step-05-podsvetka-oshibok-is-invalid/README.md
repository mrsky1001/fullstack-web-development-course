# Шаг 5. Подсветка ошибок через класс is-invalid

Связь с кодом: код этого шага находится в файле main.js.

## Как показывать ошибки пользователю

Пользователю нужно наглядно показать, где именно он ошибся. Для этого в CSS заранее создают класс .is-invalid с красной рамкой.

Алгоритм проверки:
1. Перед началом проверки всегда снимают класс ошибки (classList.remove('is-invalid')), чтобы убрать старые предупреждения.
2. Если поле заполнено неверно, ему добавляют класс ошибки (classList.add('is-invalid')).
