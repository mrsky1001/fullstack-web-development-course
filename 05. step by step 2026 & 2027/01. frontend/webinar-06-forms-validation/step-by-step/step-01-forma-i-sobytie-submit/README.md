# Шаг 1 — Форма и событие submit

## 🎯 Что изучаем
Как устроена HTML-форма `<form>` и почему при клике на кнопку «Отправить» страница пытается перезагрузиться.

---

## 💡 Что происходит по умолчанию?
Исторически в вебе, когда пользователь нажимает кнопку `<button type="submit">`, браузер собирает все поля и отправляет запрос на сервер, полностью **перезагружая страницу**.

Но в современных веб-приложениях мы хотим:
1. Сначала проверить через JS, заполнил ли пользователь поля.
2. Если есть ошибка — показать её прямо на экране без перезагрузки!

Для этого у формы есть специальное событие — **`submit`**.

```javascript
const form = document.getElementById('loginForm');

form.addEventListener('submit', function(event) {
    console.log('Пользователь нажал кнопку отправки!');
});
```
