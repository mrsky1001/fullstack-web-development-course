# Шаг 6. Проверка совпадения паролей

Связь с кодом: код этого шага находится в файле main.js.

## Операторы равенства

В JavaScript для сравнения двух значений используют:
- === (строгое равенство): проверяет, совпадают ли значения.
- !== (строгое неравенство): проверяет, различаются ли значения.

При регистрации сравнивают значение основного пароля pass.value и подтверждения confirm.value. Если они не равны, на второе поле вешают класс ошибки.
