Отмена перезагрузки: event.preventDefault()

По умолчанию отправка формы перезагружает страницу. Метод event.preventDefault() отменяет это, позволяя обработать данные с помощью JS.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 2: Отмена перезагрузки через event.preventDefault()
const form = document.getElementById('demoForm');

if (form) {
  form.addEventListener('submit', function (event) {
    event.preventDefault(); // Страница больше НЕ перезагружается!
    console.log('Отправка отменена, данные остаются на экране!');
  });
}

Совет: проверьте работу формы в браузере и откройте консоль F12.
