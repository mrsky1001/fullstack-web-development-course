# Шаг 2. Отмена перезагрузки страницы

Связь с кодом: код этого шага находится в файле main.js.

## Зачем нужен event.preventDefault()

По умолчанию при отправке формы браузер пытается перезагрузить страницу и отправить запрос на сервер.

Чтобы приложение работало быстро и без мигания экрана, мы вызываем команду event.preventDefault(). Она говорит браузеру не перезагружать страницу, чтобы JavaScript мог сам проверить данные и выполнить нужные действия.
