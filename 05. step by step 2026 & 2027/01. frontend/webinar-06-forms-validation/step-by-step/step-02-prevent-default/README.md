# Шаг 2 — e.preventDefault(): Останавливаем перезагрузку

## 🎯 Что изучаем
Как отменить стандартное поведение браузера с помощью команды `e.preventDefault()` и получить полный контроль над отправкой формы.

---

## 💡 Что такое e.preventDefault()?

Буква `e` (или `event`) — это **объект события**, который браузер автоматически передаёт в нашу функцию.

Метод `.preventDefault()` буквально переводится: **«Предотврати действие по умолчанию!»**

```javascript
const form = document.getElementById('registerForm');

form.addEventListener('submit', (e) => {
    e.preventDefault(); // 🛑 СТОП-КРАН! Страница НЕ перезагрузится!
    
    console.log('Теперь мы можем спокойно проверить все поля!');
});
```

Теперь страница остаётся на месте, пользователь не теряет набранный текст, а мы можем выполнить проверку через JavaScript.
