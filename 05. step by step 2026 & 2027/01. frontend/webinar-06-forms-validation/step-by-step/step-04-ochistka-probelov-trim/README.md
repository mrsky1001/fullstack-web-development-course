# Шаг 4 — Очистка пробелов через метод .trim()

## 🎯 Что изучаем
Зачем нужен метод `.trim()` и почему обычная проверка `if (value === '')` пропускает случайные пробелы.

---

## 💡 Проблема невидимых пробелов

Если пользователь нажал несколько пробелов в поле ввода:
`value` будет равно `'   '`.

Для компьютера строка из пробелов — НЕ пустая! У неё длина `3`, поэтому наивная проверка `if (input.value !== '')` посчитает поле заполненным!

---

## 🛠️ Решение: метод .trim()

Метод `.trim()` удаляет все пробелы **в начале и в конце** строки:

```javascript
const raw = '   Иван   ';
console.log(raw.trim()); // 'Иван'

const onlySpaces = '     ';
console.log(onlySpaces.trim()); // '' (пустая строка!)
```

Поэтому правильная проверка поля на заполненность всегда пишется так:
```javascript
if (!input.value.trim()) {
    console.log('Поле действительно пустое!');
}
```
