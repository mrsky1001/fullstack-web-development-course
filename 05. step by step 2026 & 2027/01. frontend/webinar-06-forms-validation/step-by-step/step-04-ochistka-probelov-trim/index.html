Очистка от пробелов: метод .trim()

Метод .trim() удаляет случайные пробелы в начале и в конце строки. Если пользователь ввёл только пробелы, ' '.trim() вернёт пустую строку ''.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 4: Очистка строки методом .trim()
const form = document.getElementById('demoForm');

if (form) {
  form.addEventListener('submit', function (event) {
    event.preventDefault();

    const rawEmail = document.getElementById('userEmail').value;
    const cleanEmail = rawEmail.trim();

    if (cleanEmail === '') {
      console.log('Ошибка: поле заполнено только пробелами или пустое!');
    } else {
      console.log('Очищенный email:', cleanEmail);
    }
  });
}

Совет: проверьте работу формы в браузере и откройте консоль F12.
