Тестовая форма (Шаг 3)

📚 Шаг 3 из 7

Чтение введённого текста: input.value

Свойство .value содержит текст, который пользователь ввёл в поле инпута.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 3: Чтение значения полей
const form = document.getElementById('demoForm');

if (form) {
  form.addEventListener('submit', function (event) {
    event.preventDefault();

    const email = document.getElementById('userEmail').value;
    console.log('Пользователь ввёл email:', email);
  });
}

Совет: проверьте работу формы в браузере и откройте консоль F12.
