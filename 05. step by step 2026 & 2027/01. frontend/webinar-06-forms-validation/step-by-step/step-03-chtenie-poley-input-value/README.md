# Шаг 3. Чтение значений полей: свойство .value

Связь с кодом: код этого шага находится в файле main.js.

## Разница между .textContent и .value

У обычных тегов (div, p, h1, span) текст считывают через свойство .textContent.

У тегов формы (input, textarea, select) введённое пользователем значение всегда считывают через свойство .value.
