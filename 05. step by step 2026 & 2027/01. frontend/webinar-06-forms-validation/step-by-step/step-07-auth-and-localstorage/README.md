# Шаг 7. Сохранение данных в localStorage

Связь с кодом: код этого шага находится в файле main.js.

## Что такое localStorage простыми словами

localStorage — это память браузера для вашего сайта. Данные, сохраненные туда, не пропадают при перезагрузке страницы и остаются даже после закрытия браузера.

Основные команды:
- localStorage.setItem('ключ', 'значение') — сохранить данные;
- localStorage.getItem('ключ') — прочитать данные;
- localStorage.removeItem('ключ') — удалить данные.

## Важное правило про строки
localStorage умеет хранить только текст (строки). Чтобы сохранить объект, его превращают в строку с помощью команды JSON.stringify(объект). При чтении строку превращают обратно в объект командой JSON.parse(строка).
