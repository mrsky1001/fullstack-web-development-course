# Шаг 7 — Авторизация и localStorage (Финал 6-го вебинара)

## 🎯 Что изучаем
Как проверить логин и пароль администратора (`admin` / `12345`), сохранить статус входа в постоянную память браузера (`localStorage`) и показать имя вошедшего пользователя!

---

## 💡 Что такое localStorage?

`localStorage` — это мини-хранилище прямо внутри браузера. Данные в нём **не удаляются**, даже если закрыть вкладку или перезагрузить компьютер!

У него всего 3 основных метода:
```javascript
// 1. Сохранить значение:
localStorage.setItem('currentUser', 'admin');

// 2. Прочитать значение:
const user = localStorage.getItem('currentUser'); // 'admin'

// 3. Удалить при выходе из системы:
localStorage.removeItem('currentUser');
```
