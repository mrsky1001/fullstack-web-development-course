Сохранение пользователя в localStorage

localStorage позволяет сохранять данные в браузере даже после закрытия вкладки. Объекты сохраняются через JSON.stringify().

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 7: Авторизация и localStorage
const form = document.getElementById('demoForm');

if (form) {
  form.addEventListener('submit', function (event) {
    event.preventDefault();

    const email = document.getElementById('userEmail').value.trim();
    if (email) {
      const user = { email: email, loginTime: new Date().toLocaleTimeString() };
      localStorage.setItem('currentUser', JSON.stringify(user));

      alert('Добро пожаловать! Вы авторизованы как ' + email);
      console.log('Сохранено в localStorage:', user);
    }
  });
}

Совет: проверьте работу формы в браузере и откройте консоль F12.
