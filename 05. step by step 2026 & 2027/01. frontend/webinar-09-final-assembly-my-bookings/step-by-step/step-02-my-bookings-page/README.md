# Шаг 2. Отрисовка бронирований и кнопка отмены

Связь с кодом: код этого шага находится в файле main.js.

## Как работает отмена записи

1. Пользователь нажимает кнопку «Отменить».
2. Срабатывает функция removeBooking(id).
3. Метод .filter() оставляет в массиве только те записи, чей id не равен удаляемому.
4. Обновленный массив сохраняется в localStorage.
5. Список на экране сразу перерисовывается.
