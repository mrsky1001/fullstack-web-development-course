Архитектура проекта: как все страницы связаны

Все страницы сайта (Главная, Каталог, Бронирование, Мои бронирования) связаны общим файлом data.js и хранилищем localStorage.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 1: Связка всех страниц через localStorage
console.log('Проверяем текущие сохранённые данные в системе:');
const user = localStorage.getItem('currentUser');
const bookings = localStorage.getItem('myBookings');

console.log('Авторизованный пользователь:', user ? JSON.parse(user) : 'Не авторизован');
console.log('Бронирования в памяти:', bookings ? JSON.parse(bookings) : 'Список пуст');

Совет: проверьте добавление и удаление записей в панели Application → Local Storage (F12).
