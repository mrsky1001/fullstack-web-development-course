# Шаг 1 — Как весь проект «СмартОфис» работает вместе

## 🎯 Что изучаем
Архитектурная схема взаимодействия всех 7 HTML-страниц с файлом базы данных `data.js`, таблицей стилей `style.css` и общим файлом логики `main.js`.

---

## 🗺️ Карта структуры проекта

```
📁 smart-office/
├── 📄 index.html             (Главная: Hero-баннер, слайдер, 3 популярные комнаты)
├── 📁 pages/
│   ├── 📄 catalog.html       (Каталог всех 6 комнат + поиск + сортировка)
│   ├── 📄 room-details.html  (Детали выбранной комнаты по ?id=...)
│   ├── 📄 booking.html       (Форма бронирования с живым калькулятором)
│   ├── 📄 my-bookings.html   (Личный кабинет: список забронированных офисов)
│   ├── 📄 login.html         (Форма входа admin / 12345)
│   └── 📄 register.html      (Форма регистрации с валидацией)
├── 📁 css/
│   └── 📄 style.css          (Единый дизайн всех страниц)
└── 📁 js/
    ├── 📄 data.js            (База данных: OFFICE_ROOMS и MOCK_BOOKINGS)
    └── 📄 main.js            (Все функции: навигация, слайдер, поиск, калькулятор)
```

Каждая страница подключает `data.js` и `main.js` с атрибутом `defer`, чтобы они выполнялись после загрузки HTML.
