# Шаг 3. Функция переключения слайдов

Связь с кодом: код этого шага находится в файле main.js.

## Как устроен показ слайда

В CSS все слайды спрятаны через opacity: 0. Видимым является только тот слайд, у которого есть класс .active (opacity: 1).

Функция showSlide(index) делает следующее:
1. Проверяет номер. Если номер больше общего числа слайдов — возвращает на самый первый (индекс 0).
2. Проходит по всем картинкам: той, чей номер совпал с currentSlide, вешает класс active, а с остальных снимает.
3. Точно так же подсвечивает круглую точку под слайдером.
