# Шаг 3 — Таймер setInterval: автоматическое переключение

## 🎯 Что изучаем
Как запустить циклическое переключение слайдов каждые 3000 мс (3 секунды) с помощью функции `setInterval`.

---

## 💡 Как работает setInterval?

`setInterval(действие, миллисекунды)` выполняет указанную функцию снова и снова через равные промежутки времени:

```javascript
function next() {
    showSlide(currentSlide + 1);
}

// Запустить повторение каждые 3 секунды (3000 мс):
const timerId = setInterval(next, 3000);
```

`setInterval` возвращает уникальный числовой идентификатор (ID таймера). Этот ID нужен нам, чтобы в любой момент остановить таймер через `clearInterval(timerId)`.
