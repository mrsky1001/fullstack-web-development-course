# Шаг 5. Автопрокрутка через setInterval

Связь с кодом: код этого шага находится в файле main.js.

## Что такое setInterval

Функция setInterval — это таймер браузера. Она принимает два значения:
1. Функцию, которую нужно регулярно выполнять.
2. Интервал времени в миллисекундах (1000 миллисекунд = 1 секунда).

Команда setInterval(..., 3500) будет бесконечно запускать показ следующего слайда каждые 3.5 секунды.
