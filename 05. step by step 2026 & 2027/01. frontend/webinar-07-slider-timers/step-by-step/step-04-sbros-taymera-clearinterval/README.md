# Шаг 4 — Сброс таймера через clearInterval

## 🎯 Что изучаем
Почему при ручном клике на стрелки или точки слайдера ОБЯЗАТЕЛЬНО нужно сбрасывать таймер через `clearInterval`.

---

## 💡 Баг «сумасшедшего переключения»

Представьте: таймер настроен на 3 секунды.
Прошло 2.9 секунды. Пользователь решает кликнуть на стрелку «Вперёд».
Слайд переключился от клика!
И буквально через **0.1 секунды** срабатывает старый таймер и переключает слайд ЕЩЁ РАЗ! 
Для пользователя слайды начинают мелькать как сумасшедшие.

---

## 🛠️ Решение: сброс и перезапуск

При каждом ручном клике мы:
1. Вызываем `stopAuto()` (делает `clearInterval`).
2. Показываем нужный слайд.
3. Снова вызываем `startAuto()` (запускаем 3 секунды с чистого листа).

```javascript
function startAuto() {
    stopAuto(); // Сначала очищаем старый таймер!
    timerId = setInterval(next, 3000);
}

function stopAuto() {
    if (timerId) clearInterval(timerId);
}

nextBtn.addEventListener('click', () => {
    next();
    startAuto(); // Таймер обнулён, у пользователя есть полные 3 секунды!
});
```
