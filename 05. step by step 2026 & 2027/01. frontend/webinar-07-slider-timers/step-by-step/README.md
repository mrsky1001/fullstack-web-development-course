# 📚 Шаг за шагом: Вебинар 7 — Слайдер и таймеры

## О чём этот раздел?

В этом вебинаре мы с нуля собираем интерактивный слайдер фотографий для главной страницы сайта «СмартОфис»: разбираем переменную состояния `currentSlide`, циклические проверки, клики по кнопкам и точкам, а также автоматическое переключение через `setInterval()` и сброс через `clearInterval()`.

В каждой папке шага — плоская структура файлов:
- `index.html`
- `style.css`
- `main.js`
- `README.md`
