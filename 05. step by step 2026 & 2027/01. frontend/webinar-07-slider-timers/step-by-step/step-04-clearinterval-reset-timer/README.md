# Шаг 4. Кнопки переключения вперед и назад

Связь с кодом: код этого шага находится в файле main.js.

## Как связать кнопки со сменой картинок

К каждой кнопке привязывается слушатель клика:
- при нажатии кнопки «Вперед» вызывается showSlide(currentSlide + 1);
- при нажатии кнопки «Назад» вызывается showSlide(currentSlide - 1).

Благодаря проверке границ внутри showSlide слайдер листается по кругу: после последней картинки снова покажется первая.
