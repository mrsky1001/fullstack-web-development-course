# Шаг 2. Переменная состояния слайдера

Связь с кодом: код этого шага находится в файле main.js.

## Что такое состояние программы простыми словами

Чтобы знать, какую картинку показывать сейчас, JavaScript должен помнить номер открытого слайда.

Для этого создают переменную currentSlide. Мы объявляем ее словом let, потому что ее значение постоянно меняется при каждом переключении (0, 1, 2, 3 и снова 0).
