# Шаг 2 — Область видимости переменных

## 🎯 Что изучаем
Почему переменные `currentSlide` и `timerId` объявляются **внутри** функции `initSlider()`, а не глобально на весь файл.

---

## 💡 Глобальные vs Локальные переменные

Если объявить переменную в самом верху файла:
```javascript
let currentSlide = 0; // Глобальная переменная!
```
Любой другой скрипт или функция на странице может случайно изменить её значение, что приведёт к трудноуловимым багам.

Когда мы объявляем её **внутри функции**:
```javascript
function initSlider() {
    let currentSlide = 0; // Локальная переменная!
    let timerId = null;   // Локальная переменная!

    // Они видны ТОЛЬКО внутри initSlider и надёжно защищены!
}
```
