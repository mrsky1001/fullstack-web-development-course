Автопрокрутка через setInterval()

Функция setInterval(nextSlide, 3500) автоматически переключает слайдер каждые 3.5 секунды.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 5: Автоматическая смена слайдов
const slides = document.querySelectorAll('.slide');
const dots = document.querySelectorAll('.dot');
let currentSlide = 0;

function showSlide(index) {
  if (index >= slides.length) currentSlide = 0;
  else if (index < 0) currentSlide = slides.length - 1;
  else currentSlide = index;

  slides.forEach((s, i) => s.classList.toggle('active', i === currentSlide));
  dots.forEach((d, i) => d.classList.toggle('active', i === currentSlide));
}

// Запускаем автоматический таймер
const timerId = setInterval(function () {
  showSlide(currentSlide + 1);
}, 3500);

console.log('Автопрокрутка запущена, id таймера:', timerId);

Совет: протестируйте клики и наблюдайте за сменой классов в панели Elements (F12).
