# Шаг 1. Поиск элементов слайдера

Связь с кодом: код этого шага находится в файле main.js.

## Из чего состоит слайдер

Слайдер на сайте состоит из трех частей:
1. Картинки (слайды с классом slide) — лежат друг под другом в одном блоке.
2. Кнопки-стрелки (slider-prev и slider-next) — для переключения вперед и назад.
3. Круглые точки (индикаторы dot) — показывают, какая картинка открыта прямо сейчас.

Чтобы управлять слайдером из программы, мы сначала находим все эти теги через document.querySelectorAll и document.querySelector.
