Массив объектов: наша база данных data.js

В реальных проектах данные хранятся как массив объектов: [ {room1}, {room2}, {room3} ]. Мы выносим их в отдельный файл data.js.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 3: Массив объектов из файла data.js
console.log('Загружена база данных комнат:', OFFICE_ROOMS);
console.log('Всего комнат в каталоге:', OFFICE_ROOMS.length);

// Выводим название каждой комнаты в цикле forEach
OFFICE_ROOMS.forEach(function (room, index) {
  console.log((index + 1) + '. ' + room.title + ' — ' + room.pricePerHour + ' ₽/час');
});

Совет: откройте консоль браузера (F12 → Console), чтобы увидеть результат работы скрипта.
