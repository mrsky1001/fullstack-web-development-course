# Шаг 3 — Массив объектов (наша база данных OFFICE_ROOMS)

## 🎯 Что изучаем
Что происходит, когда мы объединяем два понятия: список (массив `[]`) и карточки (объекты `{}`).
Именно так устроен файл `data.js` в проекте «СмартОфис»!

---

## 💡 Как выглядит массив объектов?

Вспомним:
- `[]` — это список
- `{}` — это карточка одной комнаты

Если положить объекты внутрь массива через запятую:

```javascript
const OFFICE_ROOMS = [
    {
        id: 'focus-1',
        title: 'Мини-офис Focus',
        pricePerHour: 450,
        equipment: ['Wi-Fi', '4K Монитор', 'Кресло']
    },
    {
        id: 'alpha-2',
        title: 'Конференц-зал Alpha',
        pricePerHour: 1200,
        equipment: ['Проектор', 'Спикерфон']
    }
];

// Как достать название первой комнаты?
console.log(OFFICE_ROOMS[0].title); // 'Мини-офис Focus'

// А цену второй комнаты?
console.log(OFFICE_ROOMS[1].pricePerHour); // 1200
```

---

## 🔗 Файл `data.js` в реальном проекте
В проекте «СмартОфис» вся база из 6 комнат вынесена в отдельный файл `js/data.js`.
Мы подключаем его в HTML ДО основного скрипта:
```html
<script src="js/data.js" defer></script>
<script src="js/main.js" defer></script>
```
И после этого переменная `OFFICE_ROOMS` доступна везде!
