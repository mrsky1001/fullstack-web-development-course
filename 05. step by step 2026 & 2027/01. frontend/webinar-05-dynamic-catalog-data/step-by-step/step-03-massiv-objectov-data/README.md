# Шаг 3. Массив объектов (data.js)

Связь с кодом: код этого шага находится в файле main.js, а данные — в файле data.js.

## Как устроены каталоги товаров и услуг

На любом реальном сайте список товаров — это массив, внутри которого лежат объекты:
```javascript
const OFFICE_ROOMS = [
  { id: 'focus-1', title: 'Мини-офис Focus', pricePerHour: 450 },
  { id: 'alpha-2', title: 'Конференц-зал Alpha', pricePerHour: 1200 },
  { id: 'hub-3', title: 'Опенспейс Hub', pricePerHour: 250 }
];
```

Каждый элемент массива — это отдельная комната со своими параметрами.

## Зачем данные хранят в файле data.js

1. Разделение труда: файл data.js содержит только сами данные. Файл main.js содержит только команды и логику работы страницы.
2. Простота правок: если изменились цены или добавилась новая комната, вы меняете только data.js, не рискуя сломать программный код.
