# Шаг 5. Метод массива .map() и отрисовка каталога

Связь с кодом: код этого шага находится в файле main.js.

## Как работает метод .map()

Метод .map() берет массив данных и превращает каждый его элемент в новый вид.

Если у нас был массив из 6 объектов комнат, метод .map() выполнит функцию 6 раз и вернет новый массив из 6 строк с HTML-разметкой карточек.

## Зачем нужен метод .join('')

Результат работы .map() — это массив строк. Если вставить массив напрямую в innerHTML, браузер разделяет элементы запятыми, и на странице между карточками появятся лишние запятые.

Метод .join('') объединяет все элементы массива в одну длинную строку без знаков препинания.
