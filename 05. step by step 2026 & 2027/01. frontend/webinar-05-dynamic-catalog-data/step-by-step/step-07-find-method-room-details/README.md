# Шаг 7. Поиск комнаты методом .find()

Связь с кодом: код этого шага находится в файле main.js.

## Как работает метод .find()

Метод .find() перебирает элементы массива и проверяет условие:
- как только находится первый подходящий элемент, поиск сразу завершается и возвращается найденный объект;
- если ни один элемент не подошел, метод вернет undefined (значение не найдено).

## Разница между .find() и .filter()
- .find() ищет ровно один элемент (по уникальному id).
- .filter() ищет список элементов (например, все комнаты дешевле 500 рублей).

Перед выводом информации на экран обязательно проверяют через if (selectedRoom), нашлась ли комната, чтобы избежать ошибок в случае неверного адреса.
