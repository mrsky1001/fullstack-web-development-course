## 💡 Что делает метод .find()?

Метод `.find()` бежит по массиву и возвращает **первый элемент**, для которого условие вернуло `true`:

```javascript
// Находим комнату, у которой поле id совпадает с тем, что пришло из ссылки:
const room = OFFICE_ROOMS.find(r => r.id === roomId);

if (!room) {
    console.log('Комната не найдена!');
} else {
    console.log('Нашли комнату:', room.title);
}
```
