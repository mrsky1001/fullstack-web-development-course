# Шаг 2 — Что такое Объект?

## 🎯 Что изучаем
Что такое объект (Object), как описать предмет со всеми его свойствами в фигурных скобках `{}` и обращаться к полям через точку.

---

## 💡 Объяснение простыми словами

Массив хорош для простого списка одинаковых вещей. Но как описать одну конкретную комнату в офисе? У неё есть:
- название (строка)
- цена за час (число)
- площадь (строка)
- фото (путь к картинке)

Для этого существует **объект**! Это как паспорт или анкета предмета:

```javascript
const room = {
    id: 'focus-1',
    title: 'Мини-офис Focus',
    pricePerHour: 450,
    area: '12 м²',
    isPopular: true
};

// Как прочитать свойство объекта? Через ТОЧКУ:
console.log(room.title);        // 'Мини-офис Focus'
console.log(room.pricePerHour); // 450
console.log(room.area);         // '12 м²'
```

---

## 🔑 Ключ и Значение
Объект состоит из пар: `ключ: значение`
- `title` — это ключ (имя свойства)
- `'Мини-офис Focus'` — значение этого свойства
