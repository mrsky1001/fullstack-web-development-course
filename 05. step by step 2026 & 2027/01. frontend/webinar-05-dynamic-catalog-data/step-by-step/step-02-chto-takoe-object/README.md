# Шаг 2. Что такое объект в JavaScript

Связь с кодом: код этого шага находится в файле main.js.

## Что такое объект простыми словами

Если массив — это просто пронумерованный список, то объект — это карточка предмета с конкретными характеристиками.

Представьте карточку товара в магазине или анкету:
- Имя: Мини-офис Focus
- Цена: 450
- Вместимость: 1-2 человека

В коде объект записывается в фигурных скобках {}. Каждая строка внутри объекта состоит из ключа (названия характеристики) и значения:
```javascript
const room = {
  title: 'Мини-офис Focus',
  pricePerHour: 450
};
```

## Как читать данные из объекта

Чтобы узнать значение свойства, пишут имя объекта, ставят точку и имя свойства:
- room.title вернет строку 'Мини-офис Focus';
- room.pricePerHour вернет число 450.
