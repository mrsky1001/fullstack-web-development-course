🏷️ Шаг 2: Что такое объект (Object)?

Объект — это сложная структура в фигурных скобках {}, объединяющая разные свойства одной сущности.

const room = { id: 'focus-1', title: 'Мини-офис Focus', pricePerHour: 450, area: '12 м²', capacity: '1-2 человека' }; // Читаем через точку: // room.title -> 'Мини-офис Focus' // room.pricePerHour -> 450
