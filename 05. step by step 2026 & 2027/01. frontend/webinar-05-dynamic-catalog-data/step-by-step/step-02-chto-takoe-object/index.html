Шаг 2 из 7

Что такое объект (Object)

Объект хранит данные в виде пар «ключ: значение». Это идеальный способ описать сущность реального мира (например, комнату в офисе).

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 2: Объекты в JavaScript
const room = {
  id: 'focus-1',
  title: 'Мини-офис Focus',
  pricePerHour: 450,
  capacity: '1-2 человека'
};

console.log('Объект комнаты:', room);
console.log('Название комнаты:', room.title);
console.log('Цена за час:', room.pricePerHour, '₽');

Совет: откройте консоль браузера (F12 → Console), чтобы увидеть результат работы скрипта.
