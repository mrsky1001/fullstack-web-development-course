# Шаг 5 — Метод .map() и отрисовка каталога

## 🎯 Что изучаем
Метод `.map()` — как превратить массив объектов `OFFICE_ROOMS` в массив готовых карточек HTML и вставить их на страницу через `.join('')`.

---

## 💡 Что делает метод .map()?

Аналогия: представьте конвейер. С одной стороны заезжают **сырые данные** (объекты комнат), машина `.map()` оборачивает каждый объект в **HTML-разметку карточки**, а с другой стороны выезжает готовый список карточек!

```javascript
// Контейнер на странице catalog.html:
const container = document.getElementById('catalogContainer');

// .map() трансформирует каждую комнату в HTML-строку:
const cardsHTML = OFFICE_ROOMS.map(room => `
  <div class="room-card">
    <h3>${room.title}</h3>
    <div class="card-price">${room.pricePerHour} ₽ / час</div>
  </div>
`).join(''); // склеиваем в одну общую строку без запятых!

// Вставляем всё в страницу:
container.innerHTML = cardsHTML;
```

---

## ⚠️ Зачем нужен `.join('')`?
Метод `.map()` возвращает массив: `['<div>1</div>', '<div>2</div>']`.
Если просто вставить массив в HTML, между элементами появятся некрасивые запятые!
Метод `.join('')` склеивает массив в одну сплошную строку без разделителей.
