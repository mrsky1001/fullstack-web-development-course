СмартОфис Шаг 5: Отрисовка каталога через .map()

⚡ Шаг 5: Генерация каталога функцией renderCatalog()

Вот точная строка из main.js 5-го вебинара. Метод .map() берёт каждую комнату и возвращает HTML-код:

function renderCatalog() { const container = document.getElementById('catalogContainer'); container.innerHTML = OFFICE_ROOMS.map(room => ` <div class="room-card"> <h3>${room.title}</h3> <div class="card-price">${room.pricePerHour} ₽ / час</div> </div> `).join(''); }
Контейнер <div id="catalogContainer"> пока пуст. Нажмите кнопку выше!
