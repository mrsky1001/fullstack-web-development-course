# Шаг 6. Параметры адресной строки (URLSearchParams)

Связь с кодом: код этого шага находится в файле main.js.

## Зачем нужны параметры в адресе страницы

Когда на сайте нажимают кнопку «Подробнее» у конкретной комнаты, страница должна понять, какую именно комнату показывать.

Для этого в адресную строку дописывают знак вопроса и параметры:
room-details.html?id=alpha-2

## Как прочитать параметр через JavaScript

В браузере есть встроенный инструмент URLSearchParams:
1. window.location.search возвращает всю часть адреса после знака вопроса.
2. new URLSearchParams(...) разбирает эту строку на отдельные переменные.
3. Метод params.get('id') достает нужное значение (например, 'alpha-2').
