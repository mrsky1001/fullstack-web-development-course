Параметры адресной строки (URLSearchParams)

Когда пользователь переходит по ссылке ?id=alpha-2, браузер может прочитать этот id с помощью встроенного объекта new URLSearchParams(window.location.search).

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 6: Чтение параметров URL
const params = new URLSearchParams(window.location.search);
const currentId = params.get('id') || 'focus-1';

console.log('Текущий id из адресной строки:', currentId);

const out = document.getElementById('urlOutput');
if (out) {
  out.textContent = 'Выбранный ID комнаты: ' + currentId;
}

Совет: откройте консоль браузера (F12 → Console), чтобы увидеть результат работы скрипта.
