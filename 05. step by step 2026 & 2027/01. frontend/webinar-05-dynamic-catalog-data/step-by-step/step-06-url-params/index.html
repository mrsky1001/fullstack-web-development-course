🔗 Шаг 6: Как работает URLSearchParams?

Параметры передаются в адресе ссылки после знака вопроса: ?id=focus-1. JS считывает их с помощью объекта URLSearchParams:

const urlParams = new URLSearchParams(window.location.search); const roomId = urlParams.get('id'); // Получили строку 'focus-1'

🎮 Нажмите на ссылку с параметром, чтобы перезагрузить страницу с новым ID:

?id=focus-1 ?id=alpha-2 ?id=hub-3 ?id=solo-4
