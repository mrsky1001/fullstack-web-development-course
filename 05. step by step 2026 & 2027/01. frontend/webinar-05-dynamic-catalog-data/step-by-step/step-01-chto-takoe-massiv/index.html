Что такое массив (Array)

Массив — это список элементов в квадратных скобках []. Элементы нумеруются с 0. Длину массива можно узнать через свойство .length.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 1: Массивы в JavaScript
const roomTypes = ['Офис', 'Переговорная', 'Конференц-зал', 'Опенспейс'];

console.log('Все типы комнат:', roomTypes);
console.log('Первый элемент (индекс 0):', roomTypes[0]);
console.log('Всего типов (длина массива):', roomTypes.length);

Совет: откройте консоль браузера (F12 → Console), чтобы увидеть результат работы скрипта.
