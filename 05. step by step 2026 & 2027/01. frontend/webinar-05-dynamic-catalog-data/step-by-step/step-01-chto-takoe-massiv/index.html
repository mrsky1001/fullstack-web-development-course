СмартОфис Шаг 1: Массивы в JavaScript

📦 Шаг 1: Что такое массив (Array)?

Массив — это список элементов в квадратных скобках []. Каждый элемент имеет номер (индекс), начиная с 0!

const roomTitles = ['Мини-офис Focus', 'Конференц-зал Alpha', 'Опенспейс Hub', 'Переговорная Solo']; // Индексы: // roomTitles[0] -> 'Мини-офис Focus' // roomTitles[1] -> 'Конференц-зал Alpha' // roomTitles[2] -> 'Опенспейс Hub' // roomTitles[3] -> 'Переговорная Solo'
