# Шаг 1. Что такое массив в JavaScript

Связь с кодом: код этого шага находится в файле main.js.

## Что такое массив простыми словами

Массив — это список значений, записанный в квадратных скобках [].

Представьте список покупок или классный журнал, где все ученики идут под номерами. Вместо того чтобы придумывать отдельную переменную для каждой записи, мы складываем все значения в один общий список:
```javascript
const roomTypes = ['Офис', 'Переговорная', 'Конференц-зал', 'Опенспейс'];
```

## Правила работы с массивами

1. Номера элементов (индексы) всегда начинаются с нуля:
- roomTypes[0] — это 'Офис';
- roomTypes[1] — это 'Переговорная';
- roomTypes[2] — это 'Конференц-зал'.

2. Свойство .length показывает общее число элементов в массиве. Для нашего списка roomTypes.length вернет 4.

3. Чтобы достать последний элемент списка, используют формулу:
roomTypes[roomTypes.length - 1].
