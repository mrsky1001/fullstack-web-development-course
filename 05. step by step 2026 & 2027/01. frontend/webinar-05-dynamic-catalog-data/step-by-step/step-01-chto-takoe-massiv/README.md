# Шаг 1 — Что такое Массив?

## 🎯 Что изучаем
Что такое массив (Array), как создать список значений в квадратных скобках `[]` и обращаться к элементам по их порядковому номеру (индексу).

---

## 💡 Объяснение простыми словами

Представь список покупок на листочке:
1. Яблоки
2. Хлеб
3. Молоко

В JavaScript такой список называется **массивом**. Только в программировании нумерация элементов всегда начинается с **нуля (0)**!

```javascript
// Создаём массив из названий комнат:
const roomTitles = ['Focus', 'Alpha', 'Hub', 'Solo'];

// Доступ по индексу (порядковому номеру):
console.log(roomTitles[0]); // 'Focus' (первый элемент)
console.log(roomTitles[1]); // 'Alpha' (второй элемент)
console.log(roomTitles[2]); // 'Hub'   (третий элемент)

// Сколько всего элементов в массиве?
console.log(roomTitles.length); // 4
```

---

## ⚠️ Важное правило:
- Первый элемент ВСЕГДА имеет индекс `0`.
- Последний элемент имеет индекс `array.length - 1`.
