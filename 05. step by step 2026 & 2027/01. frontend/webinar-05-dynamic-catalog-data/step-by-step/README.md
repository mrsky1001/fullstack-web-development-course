# Шаг за шагом: Вебинар 5 — Динамический каталог и данные

## О чём этот раздел?

В этом вебинаре мы учимся оживлять каталог комнат: хранить данные в массивах объектов (`data.js`), генерировать HTML через `.map()` и открывать детальную страницу выбранной комнаты по ID через `URLSearchParams` и `.find()`.

В каждой папке шага — плоская структура файлов:
- `index.html`
- `style.css`
- `main.js`
- `data.js` (в шагах 3-7)
- `README.md`
