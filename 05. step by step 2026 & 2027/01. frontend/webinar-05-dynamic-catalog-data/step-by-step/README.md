# 📚 Шаг за шагом: Вебинар 5 — Данные, Массивы и Динамический Каталог

## О чём этот раздел?

В предыдущем вебинаре мы научились управлять элементами на странице. 
Теперь главная задача веб-разработчика: **не писать вручную HTML для каждого товара или офиса**, а хранить данные отдельно (в виде базы данных на JS) и автоматически генерировать карточки на странице!
