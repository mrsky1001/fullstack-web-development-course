✨ Шаг 4: Шаблонные строки `${...}`

Чтобы вставлять данные комнаты прямо внутрь HTML-тегов, мы используем обратные кавычки и знак ${переменная}.

const room = { title: 'Мини-офис Focus', pricePerHour: 450 }; // Шаблонная строка: const cardHTML = ` <div class="card"> <h3>${room.title}</h3> <p>Цена: ${room.pricePerHour} ₽/час</p> </div> `;
