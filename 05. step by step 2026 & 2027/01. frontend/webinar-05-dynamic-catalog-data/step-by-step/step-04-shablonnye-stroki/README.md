# Шаг 4 — Шаблонные строки (Template Literals)

## 🎯 Что изучаем
Как вставлять переменные в HTML-разметку с помощью обратных кавычек `` ` `` и знака доллара с фигурными скобками `${}` без утомительных плюсиков `+`.

---

## 💡 Старый способ (плюсики) против Нового способа

Раньше, чтобы собрать строку из текста и переменных, приходилось писать так:
```javascript
// 😫 Старый способ с плюсами — легко запутаться в кавычках и пробелах:
const html = '<div class="card">' +
             '  <h3>' + room.title + '</h3>' +
             '  <p>' + room.pricePerHour + ' руб.</p>' +
             '</div>';
```

А в современном JavaScript появились **шаблонные строки** с обратными кавычками (клавиша `Ё` на клавиатуре):
```javascript
// 😍 Современный способ (обратные кавычки ` ` и ${...}):
const html = `
  <div class="card">
    <h3>${room.title}</h3>
    <p>${room.pricePerHour} руб.</p>
  </div>
`;
```

---

## 🔑 Правила шаблонных строк:
1. Оборачиваются только в **обратные кавычки** `` ` `` (не обычные `'` или `"`).
2. Внутри можно писать любой многострочный HTML как есть.
3. Любое выражение или переменная оборачивается в `${переменная}`.
