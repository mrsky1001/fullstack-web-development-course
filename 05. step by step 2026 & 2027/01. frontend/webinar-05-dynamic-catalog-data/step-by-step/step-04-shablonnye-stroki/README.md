# Шаг 4. Шаблонные строки в JavaScript

Связь с кодом: код этого шага находится в файле main.js.

## В чем проблема обычных кавычек

Раньше, чтобы подставить переменные в текст, приходилось склеивать строки плюсами:
```javascript
const text = '<div><h3>' + room.title + '</h3><p>' + room.price + '</p></div>';
```
При таком подходе легко пропустить кавычку или пробел.

## Обратные кавычки (клавиша Ё)

В современном JavaScript для сборки HTML используют обратные косые кавычки:
1. Они позволяют переносить строки клавишей Enter точно так же, как в HTML-файле.
2. Внутрь конструкции ${переменная} можно подставлять любые переменные или математические выражения.

Свойство container.innerHTML принимает готовую строку и превращает ее в настоящие HTML-элементы на странице.
