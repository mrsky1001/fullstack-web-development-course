# Шаг за шагом: Вебинар 8 — Фильтрация, поиск и калькулятор

## О чём этот раздел?

В этом вебинаре мы создаём живой поиск комнат без перезагрузки страницы: событие `input`, фильтрация массива методом `.filter()`, сортировка по стоимости методом `.sort()` и калькулятор бронирования.

В каждой папке шага — плоская структура файлов:
- `index.html`
- `style.css`
- `data.js`
- `main.js`
- `README.md`
