# Шаг 6. Калькулятор бронирования

Связь с кодом: код этого шага находится в файле main.js.

## Как устроен расчет

1. Пользователь вводит количество часов в поле input.
2. Функция parseInt(hoursInput.value) переводит текст в настоящее число.
3. Стоимость рассчитывается по формуле: часы * цена за час.
4. Итоговая сумма сразу выводится на экран в блок span.
