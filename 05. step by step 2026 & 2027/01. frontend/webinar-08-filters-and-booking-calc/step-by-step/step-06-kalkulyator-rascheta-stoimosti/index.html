Калькулятор бронирования (Мини-офис Focus: 450 ₽/час)

Итого к оплате: 1350 ₽
Шаг 6 из 6

Калькулятор расчёта стоимости бронирования

Умножаем количество введённых часов на почасовую ставку комнаты и выводим итоговую сумму в рублях.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 6: Калькулятор бронирования
const hoursInput = document.getElementById('calcHours');
const totalOut = document.getElementById('calcTotal');
const PRICE_PER_HOUR = 450; // Стоимость комнаты «Фокус»

function updateCalculation() {
  const hours = parseInt(hoursInput.value) || 0;
  const total = hours * PRICE_PER_HOUR;
  totalOut.textContent = total + ' ₽';
  console.log('Рассчитано:', hours, 'ч. *', PRICE_PER_HOUR, '=', total);
}

if (hoursInput && totalOut) {
  hoursInput.addEventListener('input', updateCalculation);
  updateCalculation();
}

Совет: введите поисковый запрос в поле выше и проверьте мгновенную фильтрацию.
