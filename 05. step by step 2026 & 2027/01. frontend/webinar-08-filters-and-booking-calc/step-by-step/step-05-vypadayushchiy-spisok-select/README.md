# Шаг 5. Выпадающий список select и событие change

Связь с кодом: код этого шага находится в файле main.js.

## Как работать со списком select

В HTML тег select содержит пункты option с атрибутом value.
Когда пользователь выбирает новый пункт, срабатывает событие change, а значение выбранного пункта считывают через select.value.
