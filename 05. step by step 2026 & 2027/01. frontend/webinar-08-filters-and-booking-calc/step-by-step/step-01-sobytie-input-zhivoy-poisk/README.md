# Шаг 1. Событие input: живой поиск

Связь с кодом: код этого шага находится в файле main.js.

## Разница между input и change

В полях ввода есть два похожих события:
1. change — срабатывает только тогда, когда человек закончил ввод и нажал мышкой в другое место. Для живого поиска это не подходит.
2. input — срабатывает мгновенно при каждом нажатии клавиши или удалении буквы. Это основа живого поиска, как в Яндексе или Google.
