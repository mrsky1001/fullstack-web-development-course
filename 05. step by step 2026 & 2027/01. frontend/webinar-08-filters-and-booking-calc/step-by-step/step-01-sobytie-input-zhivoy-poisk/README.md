# Шаг 1 — Событие input: Живой поиск

## 🎯 Что изучаем
Разница между событиями `change` и `input`, и почему для живого поиска подходит именно `input`.

---

## 💡 Событие input срабатывает на каждый символ!

- Событие `change` срабатывает только тогда, когда пользователь закончил ввод и **кликнул мышкой вне поля** (убрал фокус). Для поиска это неудобно!
- Событие `input` срабатывает **мгновенно при каждом нажатии клавиши**, удалении буквы или вставке текста.

```javascript
const searchInput = document.getElementById('searchInput');

searchInput.addEventListener('input', () => {
    console.log('Текущий текст поиска:', searchInput.value);
});
```
