Событие input: живой поиск

Событие input срабатывает мгновенно при каждом нажатии клавиши или изменении текста в поле ввода.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 1: Живой отклик на ввод текста
const searchInput = document.getElementById('demoSearch');

if (searchInput) {
  searchInput.addEventListener('input', function () {
    console.log('Пользователь вводит:', searchInput.value);
  });
}

Совет: введите поисковый запрос в поле выше и проверьте мгновенную фильтрацию.
