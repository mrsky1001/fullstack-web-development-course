# Шаг 4 — Метод .sort() и функция-компаратор

## 🎯 Что изучаем
Как отсортировать объекты по числовому свойству (цене) по возрастанию и по убыванию.

---

## 💡 Как работает компаратор (a, b)?

Метод `.sort()` принимает функцию сравнения двух соседних элементов:

```javascript
// 1. По возрастанию (от дешёвых к дорогим):
// Если (a - b) отрицательное -> a идёт раньше b
rooms.sort((a, b) => a.pricePerHour - b.pricePerHour);

// 2. По убыванию (от дорогих к дешёвым):
// Если (b - a) положительное -> b идёт раньше a
rooms.sort((a, b) => b.pricePerHour - a.pricePerHour);
```
