📋 Шаг 3: Безопасное копирование массива

Смотрите: [...OFFICE_ROOMS] создаёт точную независимую копию списка:

const original = [1, 2, 3]; const copy = [...original]; // Копия! copy.push(99); console.log(original); // [1, 2, 3] (оригинал не изменился!) console.log(copy); // [1, 2, 3, 99]
