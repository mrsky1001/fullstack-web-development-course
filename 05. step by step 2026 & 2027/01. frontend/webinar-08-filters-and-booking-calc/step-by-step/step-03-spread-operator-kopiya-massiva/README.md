# Шаг 3. Спред-оператор [...] для копирования массива

Связь с кодом: код этого шага находится в файле main.js.

## Почему нельзя просто написать const b = a

В JavaScript массивы копируются по ссылке. Если написать const b = a, то при изменении b изменится и исходный массив a.

Перед сортировкой каталога нужно делать независимую копию через спред-оператор: [...OFFICE_ROOMS]. Тогда сортировка на экране не испортит исходный порядок базы данных.
