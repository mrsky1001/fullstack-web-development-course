# Шаг 3 — Spread-оператор [...array] (копия массива)

## 🎯 Что изучаем
Зачем нужен синтаксис с тремя точками `[...OFFICE_ROOMS]` и почему метод сортировки `.sort()` может сломать исходные данные, если не сделать копию.

---

## ⚠️ Опасность метода .sort()
Большинство методов массивов (например, `.map()`, `.filter()`) создают **новый** массив, не трогая исходный.
Но метод `.sort()` — мутирующий! Он **переставляет элементы прямо в исходном массиве**!

Если мы отсортируем оригинальный `OFFICE_ROOMS`, мы навсегда потеряем его первоначальный порядок.

---

## 🛡️ Создание независимой копии: `[...array]`
Оператор расширения (spread) раскладывает элементы массива в новый контейнер:

```javascript
// Создаём независимую копию:
let displayedRooms = [...OFFICE_ROOMS];

// Теперь можно безопасно сортировать displayedRooms — исходный OFFICE_ROOMS останется целым!
displayedRooms.sort((a, b) => a.pricePerHour - b.pricePerHour);
```
