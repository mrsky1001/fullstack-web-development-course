DOM-дерево и поиск элемента

Когда браузер загружает HTML — он строит DOM-дерево в памяти. JS работает с этим деревом!

// Найти элемент по id: const slide1El = document.getElementById('slide1'); // Найти по CSS-селектору: const btn = document.querySelector('.slider-next'); // Найти ВСЕ совпадающие элементы: const allSlides = document.querySelectorAll('.slide');
