DOM-дерево и поиск элементов

Браузер превращает HTML в дерево объектов (DOM). Чтобы найти тег из JavaScript, мы используем document.querySelector.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 3: Поиск элементов в DOM
// Ищем логотип по CSS-классу
const logo = document.querySelector('.logo');
console.log('Найденный логотип:', logo);

// Ищем все ссылки навигации
const navLinks = document.querySelectorAll('.nav-link');
console.log('Количество ссылок в меню:', navLinks.length);

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
