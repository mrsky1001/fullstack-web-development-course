# Шаг 3. DOM-дерево и поиск элементов

Связь с кодом: код этого шага находится в файле main.js.

## Что такое DOM простыми словами

Когда браузер открывает HTML-файл, он переводит все теги в дерево объектов в оперативной памяти. Это дерево называется DOM (Document Object Model).

Каждый тег на странице становится отдельным объектом:
- вся страница целиком доступна через специальное слово document;
- через document JavaScript может найти любой тег, прочитать его текст или поменять цвет.

## Как найти элемент на странице

В JavaScript используются те же селекторы, что и в CSS:

1. document.querySelector('селектор')
Находит самый первый тег на странице, который подходит под указанный селектор.
Если элемент не найден, вернет пустоту (null).
Примеры:
- document.querySelector('.logo') — найдет элемент с классом logo.
- document.querySelector('#authBtn') — найдет элемент с идентификатором authBtn.
- document.querySelector('header') — найдет тег header.

2. document.querySelectorAll('селектор')
Находит сразу все подходящие теги и возвращает их в виде списка (коллекции NodeList).
У этой коллекции есть свойство .length, которое показывает, сколько элементов нашлось.

## Номера элементов (индексы)

Компьютер всегда начинает считать с нуля, а не с единицы:
- navLinks[0] — это первый найденный элемент списка;
- navLinks[1] — второй элемент;
- navLinks[2] — третий элемент.

Свойство .textContent позволяет прочитать или изменить текст внутри найденного тега.
