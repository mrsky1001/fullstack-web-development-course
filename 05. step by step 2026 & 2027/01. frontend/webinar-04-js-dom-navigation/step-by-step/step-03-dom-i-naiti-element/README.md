# Шаг 3. DOM-дерево и поиск элементов

## Цель шага
Научиться находить элементы страницы из JavaScript с помощью методов `document.querySelector` и `document.querySelectorAll`.

## Структура файлов:
- `index.html`
- `style.css`
- `main.js`

## Код в `main.js`:
```javascript
const logo = document.querySelector('.logo');
const navLinks = document.querySelectorAll('.nav-link');
```
