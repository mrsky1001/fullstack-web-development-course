События и клики (addEventListener)

Метод addEventListener('click', ...) позволяет реагировать на действия пользователя (клик мыши, нажатие клавиши).

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 6: События и клики
const loginBtn = document.querySelector('.nav-btn');

if (loginBtn) {
  loginBtn.addEventListener('click', function (event) {
    event.preventDefault(); // предотвращаем переход по пустой ссылке #
    alert('Вы нажали на кнопку «Войти»!');
    console.log('Клик по кнопке входа зафиксирован!');
  });
}

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
