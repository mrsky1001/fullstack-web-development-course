# Шаг 7. Перебор элементов через forEach

Связь с кодом: код этого шага находится в файле main.js.

## Зачем нужен цикл перебора

Когда мы находим все ссылки через querySelectorAll, мы получаем список из нескольких элементов.

Мы не можем написать navLinks.classList.add('active'), потому что у всего списка целиком нет классов — классы есть только у каждой отдельной ссылки внутри этого списка.

Чтобы применить действие к каждой ссылке по очереди, используется метод forEach.

## Как работает forEach

Слово forEach переводится как «для каждого».
```javascript
navLinks.forEach(function (link, index) {
  // код выполнится для первой ссылки, потом для второй, потом для третьей
});
```

Внутрь функции передаются два значения:
1. link — сам элемент на текущем шаге.
2. index — порядковый номер элемента в списке (0, 1, 2...).
