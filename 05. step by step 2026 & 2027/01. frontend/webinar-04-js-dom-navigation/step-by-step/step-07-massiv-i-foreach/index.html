Перебор элементов через forEach

Когда у нас несколько одинаковых элементов (например, ссылки меню), мы обходим их циклом forEach.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 7: Перебор элементов
const navLinks = document.querySelectorAll('.nav-link');

console.log('Список всех пунктов меню:');
navLinks.forEach(function (link, index) {
  console.log((index + 1) + '. ' + link.textContent.trim());
});

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
