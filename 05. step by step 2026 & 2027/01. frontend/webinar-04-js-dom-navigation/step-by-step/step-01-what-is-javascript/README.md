# Шаг 1. Что такое JavaScript и как он работает

Связь с кодом: код этого шага находится в файле main.js.

## Что такое JavaScript простыми словами

Любой сайт строится из трех главных частей:
1. HTML создает элементы: текст, картинки, кнопки, ссылки и поля ввода.
2. CSS оформляет элементы: задает цвета, шрифты, размеры и отступы.
3. JavaScript оживляет страницу: заставляет кнопки реагировать на нажатия, меняет текст без перезагрузки экрана и выполняет вычисления.

Если сравнить сайт с автомобилем, то HTML — это кузов и сиденья, CSS — это цвет краски и дизайн салона, а JavaScript — это двигатель и электроника.

## Как подключить JavaScript к странице

Скрипт подключается в файле index.html с помощью тега script:

```html
<script src="main.js" defer></script>
```

### Зачем нужен атрибут defer
Браузер читает HTML-документ строго сверху вниз:
- Без атрибута defer браузер остановит показ страницы, пока не скачает и не выполнит весь скрипт.
- С атрибутом defer браузер скачивает скрипт в фоновом режиме и запускает его ровно тогда, когда вся страница уже готова и отображена на экране.

## Консоль разработчика (клавиша F12)

Пользователи сайта видят только красивый интерфейс. Программист во время работы смотрит в специальную панель отладки — консоль:
1. Откройте файл index.html в любом браузере.
2. Нажмите клавишу F12 на клавиатуре (или правой кнопкой мыши в любом месте страницы -> «Посмотреть код»).
3. Перейдите на вкладку Console.
4. Вы увидите строку: «Привет, мир! Скрипт main.js успешно подключен.».

Команда console.log() выводит туда любые подсказки, числа и результаты работы программы.
