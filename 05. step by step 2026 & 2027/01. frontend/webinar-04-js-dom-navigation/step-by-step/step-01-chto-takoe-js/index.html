Что такое JavaScript и как его подключить

JavaScript оживляет страницу. Мы подключаем файл main.js через тег <script src="main.js" defer></script> в теге <head>.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 1: Первое знакомство с JavaScript
// Команда console.log выводит сообщение в консоль разработчика (F12)
console.log('Привет, мир! Скрипт main.js успешно подключён.');

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
