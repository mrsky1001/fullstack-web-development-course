# Шаг 1 — Что такое JavaScript?

## 🎯 Что изучаем
Как JavaScript подключается к странице и как написать первые три строки кода.

---

## 💡 Объяснение простыми словами

Представь: HTML — это **скелет** сайта (структура), CSS — это **одежда** (внешний вид), а JavaScript — это **мышцы и мозг** (поведение, движение, интерактивность).

Без JS сайт «мёртвый» — он просто показывает текст и картинки. С JS — он реагирует на клики, меняет содержимое, двигает слайдер!

---

## 📖 Как подключить JS?

В файле `index.html` в самом **конце `<body>`** добавляем одну строку:

```html
<script src="js/main.js"></script>
```

Это говорит браузеру: «Загрузи и выполни файл `main.js`».

> ⚠️ Почему в конце `<body>`, а не в `<head>`? Потому что сначала браузер должен построить всю страницу (HTML), и только потом JS может работать с её элементами.

---

## 💻 Первые две команды JS

```javascript
// Вывести сообщение в консоль браузера (F12 → Console)
console.log('Привет от JavaScript!');

// Показать всплывающее окно пользователю
alert('Страница загружена!');
```

`console.log` — лучший друг разработчика. Используй его чтобы проверять значения переменных.

---

## 🖥️ Что делает index.html в этом шаге

Открой `index.html` в браузере — увидишь страницу СмартОфис со слайдером.
Потом нажми **F12** → вкладка **Console** — там увидишь сообщение от JS.
Под слайдером есть кнопка «Показать alert» — нажми её!
