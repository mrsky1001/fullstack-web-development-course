# Шаг 1. Что такое JavaScript и как его подключить

## Цель шага
Узнать, как JavaScript подключается к веб-странице, и вывести первое сообщение в консоль браузера.

## Структура файлов шага:
- `index.html` — разметка страницы и подключение внешнего скрипта `<script src="main.js" defer></script>`.
- `style.css` — стили для страницы и учебной панели.
- `main.js` — код JavaScript.

## Код в `main.js`:
```javascript
console.log('Привет, мир! Скрипт main.js успешно подключён.');
```

## Как проверить:
1. Откройте `index.html` в браузере.
2. Нажмите клавишу `F12` (или правой кнопкой мыши -> «Посмотреть код»).
3. Перейдите на вкладку **Console** — там появится сообщение.
