Переменные let и const

Переменные хранят данные. Используйте const для значений, которые не меняются, и let для значений, которые будут перезаписываться.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 2: Переменные let и const
const siteName = 'СмартОфис';
const roomsCount = 6;
let currentCity = 'Москва';

console.log('Проект:', siteName);
console.log('Количество комнат:', roomsCount);
console.log('Город:', currentCity);

// Переменную let можно изменить:
currentCity = 'Санкт-Петербург';
console.log('Новый город:', currentCity);

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
