Переменные: const и let

Переменная — это именованная «коробочка» для хранения данных:

const siteName = 'СмартОфис'; // const — нельзя менять let currentSlide = 0; // let — можно менять console.log(siteName); // Выведет: СмартОфис console.log(currentSlide); // Выведет: 0
