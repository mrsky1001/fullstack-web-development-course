# Шаг 2 — Переменные (const и let)

## 🎯 Что изучаем
Что такое переменная, разница между `const` и `let`, и как это связано с нашим слайдером.

---

## 💡 Объяснение простыми словами

Переменная — это **именованная коробочка** для хранения данных.

Представь: у тебя есть ящик с наклейкой «имя». Ты кладёшь туда «Алиса». Теперь везде в коде, где написано `имя`, браузер знает — там «Алиса».

```javascript
const имя = 'Алиса';    // Коробочка «имя» с содержимым «Алиса»
console.log(имя);       // Браузер вытащит «Алиса» и выведет в консоль
```

---

## 📖 const vs let

```javascript
// const — НЕЛЬЗЯ менять значение (константа)
const pi = 3.14;
const siteName = 'СмартОфис';

// let — МОЖНО менять значение
let currentSlide = 0;    // Сначала 0
currentSlide = 1;        // Теперь 1 — ОК!
currentSlide = 2;        // Теперь 2 — тоже ОК!
```

> 💡 **Правило:** Всегда начинай с `const`. Если понял что значение будет меняться — используй `let`.

---

## 🔗 Связь с нашим слайдером

Посмотри на код из реального проекта (`smart-office-project/js/main.js`):

```javascript
// Студенты уже написали эти строки на занятии:
const slide1El = document.getElementById('slide1');
const slide2El = document.getElementById('slide2');
const slide3El = document.getElementById('slide3');
const slide4El = document.getElementById('slide4');
```

`const` — потому что сам элемент слайда не меняется (мы его не заменяем новым элементом).
Мы только меняем его **классы** — но это уже шаг 4!
