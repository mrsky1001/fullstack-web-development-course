# Шаг 2. Переменные let и const

## Цель шага
Понять разницу между переменными `const` (константа) и `let` (изменяемая переменная).

## Структура файлов:
- `index.html` — подключает `style.css` и `main.js`.
- `style.css` — стили шага.
- `main.js` — создание переменных разных типов (строка, число) и вывод их в консоль.

## Код в `main.js`:
```javascript
const siteName = 'СмартОфис';
const roomsCount = 6;
let currentCity = 'Москва';

console.log('Проект:', siteName);
console.log('Количество комнат:', roomsCount);
```
