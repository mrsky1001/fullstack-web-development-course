# Шаг 2. Переменные let и const

Связь с кодом: код этого шага находится в файле main.js.

## Что такое переменная простыми словами

Переменная — это именованная ячейка памяти компьютера, в которую мы кладем данные, чтобы использовать их дальше в коде.

Представьте картонную коробку, на которой вы написали слово «город», а внутрь положили лист с надписью «Москва». Когда вам понадобится узнать город, вы просто берете эту коробку по ее имени.

## Разница между const и let

В современном JavaScript переменные объявляют двумя словами:

1. const (константа)
Значение задается один раз и навсегда. Изменить его нельзя.
Пример: название сайта, дата запуска, ссылки на кнопки страницы.
Используется по умолчанию почти для всех переменных.

2. let (переменная)
Значение можно свободно перезаписывать в любой момент.
Пример: счетчик очков в игре, номер текущего слайда, город пользователя.
Используется только тогда, когда значение обязательно будет меняться.

Почему не используют старое слово var:
Раньше вместо let и const использовали var. В современном коде его не применяют, потому что var допускает незаметные ошибки и путает границы видимости переменных.

## Базовые типы данных

В этом шаге используются два базовых типа:
1. Строка (текст) — обязательно оборачивается в кавычки: 'СмартОфис' или 'Москва'.
2. Число — пишется без кавычек: 6 или 450. Если написать число в кавычках '6', компьютер будет считать его обычным текстом, а не цифрой.

## Правила названий

Имена переменных принято писать в стиле camelCase (верблюжий регистр):
- первое слово начинается с маленькой буквы;
- каждое следующее слово пишется с заглавной буквы без пробелов;
- примеры: siteName, roomsCount, currentUser.
