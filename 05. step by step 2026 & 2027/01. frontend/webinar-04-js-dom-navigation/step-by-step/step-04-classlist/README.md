# Шаг 4. Управление классами через classList

## Цель шага
Понять, как JavaScript управляет внешним видом элементов, добавляя и убирая CSS-классы.

## Методы classList:
- `element.classList.add('className')` — добавить класс.
- `element.classList.remove('className')` — удалить класс.
- `element.classList.contains('className')` — проверить наличие класса (вернёт true/false).
