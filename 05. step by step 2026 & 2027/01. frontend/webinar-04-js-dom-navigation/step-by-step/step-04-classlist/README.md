# Шаг 4. Управление классами через classList

Связь с кодом: код этого шага находится в файле main.js.

## Почему оформление меняют через классы

В программировании важно разделять задачи:
- Стили и внешний вид описываются в файле CSS (например, класс .active делает текст синим и жирным).
- JavaScript не должен напрямую красить элементы строками вроде style.color = 'blue'.
- Вместо этого JavaScript просто вешает или снимает готовый CSS-класс.

## Методы объекта classList

У каждого элемента на странице есть инструмент classList. Он умеет выполнять четыре действия:

1. element.classList.add('имя-класса')
Добавляет класс элементу. Если такой класс уже есть, повторно он добавлен не будет.

2. element.classList.remove('имя-класса')
Удаляет класс у элемента.

3. element.classList.toggle('имя-класса')
Работает как выключатель света: если класса не было — добавляет его, если класс был — удаляет.

4. element.classList.contains('имя-класса')
Проверяет наличие класса. Возвращает ответ «да» (true) или «нет» (false).

## Как проверить работу
Откройте вкладку Elements в панели разработчика F12. Найдите тег ссылки nav-link. Вы увидите, что после выполнения скрипта у тега появился класс active: class="nav-link active".
