Управление CSS-классами через classList

Свойство classList позволяет добавлять (add), удалять (remove) и переключать (toggle) CSS-классы у любого элемента.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 4: Управление классами
const firstLink = document.querySelector('.nav-link');

// Добавляем класс active
firstLink.classList.add('active');
console.log('Класс active добавлен к первой ссылке');

// Проверяем, есть ли класс
console.log('Есть ли класс active?', firstLink.classList.contains('active'));

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
