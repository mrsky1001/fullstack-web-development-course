# 📚 Шаг за шагом: Вебинар 4 — Основы JavaScript, DOM и Навигация

## О чём этот раздел?

Здесь мы разбираем JavaScript с **абсолютного нуля** для 1-го курса: переменные, поиск элементов в DOM, управление классами, функции, события и сборка интерактивной навигации сайта «СмартОфис».

Каждый шаг — это одна простая концепция. В каждой папке шага есть раздельные файлы:
- `index.html` — разметка страницы шага
- `style.css` — стили шага
- `main.js` — чистый скрипт шага
- `README.md` — теория и инструкция
