# 📚 Шаг за шагом: Вебинар 4 — JavaScript и Слайдер

## О чём этот раздел?

Здесь мы разбираем JavaScript с **абсолютного нуля** — и к последнему шагу собираем полностью рабочий слайдер фотографий для проекта «СмартОфис».

Каждый шаг — это одна новая концепция. Открывай `index.html` каждого шага прямо в браузере и смотри результат!
