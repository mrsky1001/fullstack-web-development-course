# Шаг 5. Функции в JavaScript

Связь с кодом: код этого шага находится в файле main.js.

## Что такое функция простыми словами

Функция — это отдельная именованная инструкция. Вы один раз описываете, что нужно сделать, даете этой инструкции понятное имя, а потом можете запускать ее в любой момент одной строкой.

Представьте кнопку на чайнике: внутри чайника сложная схема нагрева, но вам не нужно собирать ее заново каждый раз. Вы просто нажимаете кнопку включения.

## Из чего состоит функция

```javascript
function highlightLink(linkElement) {
  linkElement.classList.add('active');
}
```

1. Ключевое слово function сообщает компьютеру, что начинается объявление функции.
2. Имя функции (highlightLink) пишется глаголом и говорит о том, какое действие выполняется.
3. Круглые скобки содержат параметры — данные, которые функция ждет на вход для работы.
4. Фигурные скобки { ... } содержат само тело функции (набор команд).

## Вызов функции
Чтобы функция сработала, ее нужно вызвать по имени, указав круглые скобки:
```javascript
highlightLink(allLinks[1]);
```
Если забыть круглые скобки и написать просто имя highlightLink, функция не выполнится.
