# Шаг 5 — Функции

## 🎯 Что изучаем
Что такое функция, как её объявить и вызвать — и как наши первые строки слайдера превратились в функцию `sliderClick()`.

---

## 💡 Объяснение простыми словами

Функция — это **именованный блок кода**, который можно запустить в любое время, вызвав по имени.

Аналогия: рецепт блинов. Записал рецепт один раз — печёшь хоть 100 раз.

```javascript
// Объявление функции (записали рецепт)
function greet(name) {
    console.log('Привет, ' + name + '!');
}

// Вызов функции (приготовили блины)
greet('Алиса');   // Выведет: Привет, Алиса!
greet('Вебинар'); // Выведет: Привет, Вебинар!
```

---

## 📖 Анатомия функции

```javascript
//    ↓ ключевое слово  ↓ имя    ↓ параметры (необязательно)
function sliderClick() {
    //  ↑ открывающая скобка

    // Тело функции — что выполняется при вызове:
    slide1El.classList.remove('active');
    slide3El.classList.add('active');

}  // ← закрывающая скобка

// Вызов функции — по имени со скобками:
sliderClick();
```

## 🔗 Из кода проекта

Вот та самая функция из `smart-office-project/js/main.js`:

```javascript
// Функция которую студенты написали на занятии!
function sliderClick() {
    slide1El.classList.remove('active');
    slide3El.classList.add('active');
}

// И потом вызвали её при клике на кнопку:
rightSliderBtnEl.addEventListener('click', sliderClick);
```
