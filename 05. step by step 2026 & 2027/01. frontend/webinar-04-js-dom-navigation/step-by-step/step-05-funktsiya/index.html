Функции — именованные блоки кода

Функция — записанный «рецепт». Можно вызывать сколько угодно раз:

function sliderClick() { slide1El.classList.remove('active'); // Прячем слайд 1 slide3El.classList.add('active'); // Показываем слайд 3 } // Вызвать функцию: sliderClick(); // Запускаем рецепт!

🎮 Нажми кнопку — вызовется функция sliderClick():

Нажми кнопку — функция переключит на слайд 3...

⚠️ Пока функция несовершенна — всегда показывает слайд 3. Исправим в шаге 8!
