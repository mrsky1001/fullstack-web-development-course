Функции в JavaScript

Функция — это именованный блок кода, который можно вызывать сколько угодно раз. Она помогает не дублировать код.

Код, который выполняется в этом шаге (откройте main.js):

// Шаг 5: Функции
// Объявляем функцию
function highlightLink(linkElement) {
  linkElement.classList.add('active');
  console.log('Ссылка успешно подсвечена:', linkElement.textContent.trim());
}

// Находим вторую ссылку («Каталог») и вызываем функцию
const allLinks = document.querySelectorAll('.nav-link');
if (allLinks.length > 1) {
  highlightLink(allLinks[1]);
}

Совет: откройте консоль браузера (F12 → Вкладка Console), чтобы увидеть результат работы скрипта.
