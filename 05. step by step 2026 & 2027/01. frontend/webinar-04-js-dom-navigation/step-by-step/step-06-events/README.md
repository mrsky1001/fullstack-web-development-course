# Шаг 6. События и клики (addEventListener)

Связь с кодом: код этого шага находится в файле main.js.

## Как браузер понимает действия пользователя

Браузер постоянно следит за тем, что делает человек на странице. Каждое действие называется событием:
- клик мышью — событие 'click';
- ввод буквы с клавиатуры — событие 'input';
- отправка формы — событие 'submit'.

С помощью метода addEventListener мы учим JavaScript ждать нужное событие на выбранном элементе и сразу выполнять указанную функцию.

## Метод addEventListener

Синтаксис:
```javascript
элемент.addEventListener('событие', функция);
```

Слово «listener» переводится как «слушатель». Мы как бы приставляем к кнопке наблюдателя, который ждет щелчка мыши.

## Что делает event.preventDefault()

У некоторых тегов есть стандартное поведение:
- ссылка тега а пытается перейти по адресу в атрибуте href;
- форма тега form пытается перезагрузить страницу.

Команда event.preventDefault() отменяет это стандартное действие браузера, чтобы мы могли обработать нажатие сами через JavaScript без скачков и перезагрузок.
