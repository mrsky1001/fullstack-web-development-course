# Шаг 9. Финальная сборка модуля навигации

Связь с кодом: код этого шага находится в файле main.js.

## Зачем оборачивать код в функцию

В реальных проектах на одной странице работает много разных скриптов: навигация, слайдер, формы, калькулятор.

Если писать все команды сплошным текстом, код быстро превратится в нечитаемую кашу. Поэтому каждую задачу оформляют в виде отдельной функции:
- initNavigation() отвечает только за меню;
- initSlider() будет отвечать только за слайдер;
- initForms() будет отвечать только за формы.

## Событие DOMContentLoaded

```javascript
document.addEventListener('DOMContentLoaded', function () {
  initNavigation();
});
```

Это событие сообщает, что браузер закончил чтение HTML-разметки и построил дерево элементов. Теперь можно безопасно искать любые кнопки и вешать на них обработчики.
