# Шаг 8. Переключение активного пункта меню при клике

Связь с кодом: код этого шага находится в файле main.js.

## Правило одного активного элемента

В меню сайта в каждый момент времени должна быть выделена только одна ссылка — та, на которую нажал пользователь.

Если просто добавить класс нажатой ссылке, предыдущая ссылка останется подсвеченной, и через три клика подсвеченными окажутся сразу все пункты меню.

## Пошаговый алгоритм

Когда происходит клик по любой ссылке меню, скрипт выполняет два шага:
1. Сначала обходит все ссылки меню и у каждой убирает класс active. Теперь ни одна ссылка не подсвечена.
2. Затем берет именно ту ссылку, по которой кликнули (переменная link), и добавляет ей класс active.

В результате всегда подсвечен ровно один выбранный пункт.
