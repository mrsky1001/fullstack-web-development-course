# 🎓 Курс «Веб-разработка» — Пошаговое создание интернет-портала «СмартОфис»

## 📋 О курсе
- **Целевая аудитория:** Школьники (начиная с 9 класса) и студенты 1 курса колледжа.
- **Цель курса:** С нуля, без сложных библиотек и фреймворков, создать полноценный, современный и интерактивный сайт интернет-портала бронирования офисных пространств **«СмартОфис»**.
- **Технологический стек:** HTML5 (семантическая разметка), CSS3 (Flexbox, шрифт Inter, чистая светлая тема), JavaScript (Vanilla JS — DOM, таймеры, массивы, фильтрация, калькулятор, детальные страницы).
- **Время на итоговую сборку на экзамене:** 120 минут (2 часа).

## 📁 Структура каждого вебинара
Каждая папка урока (начиная со 2-го вебинара) содержит две версии проекта:
1. **`basic/`** — максимально простой, чистый и лаконичный код без комментариев. Идеален для написания преподавателем на доске или быстрого набора на занятии.
2. **`with-comments/`** — подробно прокомментированная версия с пометками `[Теория]` (объяснение концепции простыми словами) и `[Логика]` (зачем нужна эта строчка в проекте). Идеальна для домашнего и самостоятельного изучения.

## 📄 Итоговое дерево файлов проекта (7 страниц)
```text
smart-office/
├── index.html               # Главная страница (шапка, слайдер, популярные комнаты, подвал)
├── pages/
│   ├── catalog.html         # Каталог офисов с живым поиском и сортировкой по цене
│   ├── room-details.html    # Страница описания конкретной комнаты (фото, площадь, удобства)
│   ├── booking.html         # Оформление бронирования с моментальным расчетом стоимости
│   ├── my-bookings.html     # История заявок пользователя (или заглушка)
│   ├── register.html        # Регистрация с проверкой полей
│   └── login.html           # Вход в систему (логин: admin, пароль: 12345)
├── css/
│   └── style.css            # Единая таблица стилей для всех 7 страниц
├── js/
│   ├── data.js              # База данных офисов и бронирований
│   └── main.js              # Вся логика сайта (слайдер, навигация, валидация, калькулятор, описание)
└── img/                     # Логотип и фотографии комнат
```

## 🎨 Дизайн-система проекта
- **Цвета:** Белый (`#ffffff`), Темно-серый (`#222222`), Фирменный синий (`#007bff`), Фоновый светло-серый (`#f8f9fa`).
- **Шрифт:** Inter (подключается через Google Fonts).
- **Сетка:** Фиксированная ширина контейнера 1200px с горизонтальным центрированием.
