## 💡 Теоретический минимум
1. **Перехват отправки формы:** Метод `event.preventDefault()` для предотвращения перезагрузки страницы.
2. **Валидация полей:** Получение значений через `input.value.trim()` и проверка условий.
3. **Классы состояния в CSS:** Добавление `.is-invalid` для рамки `border-color: #dc3545`.
4. **Уведомления для пользователя:** Кастомный блок алерта или вызов `alert()`.

## 📝 Пошаговый план выполнения
1. Создать файлы `pages/register.html` и `pages/login.html` с центрированной карточкой формы `.auth-card`.
2. В `css/style.css` оформить поля ввода `.form-input`, лейблы `.form-label` и класс ошибок `.is-invalid` с красной подсветкой.
3. В `js/main.js` написать функцию валидации формы регистрации:
   ```javascript
   function initRegisterForm() {
     const form = document.getElementById('registerForm');
     if (!form) return;
     
     form.addEventListener('submit', (e) => {
       e.preventDefault();
       let isValid = true;
       
       const pass = document.getElementById('regPassword');
       const confirmPass = document.getElementById('regConfirmPassword');
       
       // Сброс предыдущих ошибок
       form.querySelectorAll('.form-input').forEach(input => input.classList.remove('is-invalid'));
       
       // Проверка совпадения паролей
       if (pass.value !== confirmPass.value || pass.value.length < 4) {
         pass.classList.add('is-invalid');
         confirmPass.classList.add('is-invalid');
         isValid = false;
       }
       
       if (isValid) {
         alert('Пользователь зарегистрирован успешно!');
         window.location.href = 'login.html';
       }
     });
   }
   ```
4. В `js/main.js` написать функцию проверки авторизации для `loginForm`.
