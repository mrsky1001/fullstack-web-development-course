## 💡 Теоретический минимум
1. **Семантика HTML5:** Почему `<header>` и `<nav>` лучше бессмысленных `<div>`.
2. **Центрирование контента:** Использование фиксированного/максимального контейнера `margin: 0 auto` с `padding: 0 15px`.
3. **Flexbox для выравнивания:** `display: flex`, `justify-content: space-between`, `align-items: center` в шапке и подвале.
4. **Типографика:** Подключение Google Fonts (Inter) через `<link>` с оптимизацией `preconnect`.

---

## 📝 Пошаговый план выполнения
1. Создать базовый файл `index.html` с метатегами и подключением Google Fonts (Inter).
2. Создать файл `css/style.css`, настроить сброс отступов и стили для `body` (`min-height: 100vh`, `min-width: 1200px`).
3. Сверстать тег `<header>` с классом `.header`:
   - Логотип со ссылкой на `index.html` и иконкой `img/logo.svg`.
   - Список навигации `<ul class="nav-list">` со ссылками на страницы.
4. Сверстать секцию `.hero-section` внутри `<main>`:
   - Заголовок `<h1>` с подсветкой слова «СмартОфис» (`.brand-highlight`).
   - Разделительную полосу и блок метрик `.hero-metrics`.
5. Сверстать тег `<footer>` с классом `.footer` (информация о компании + кликабельные контакты).
