## 💡 Теоретический минимум
1. **Атрибут `defer`:** Загружает JS-файл параллельно с HTML-парсингом и гарантирует выполнение после построения DOM-дерева.
2. **Объект `window.location`:** Свойства `pathname` и `href` для анализа текущего URL.
3. **Методы DOM API:**
   - `document.querySelectorAll()` — выборка коллекции элементов по CSS-селектору.
   - `element.classList.add()` / `element.classList.remove()` — безопасное управление CSS-классами.
   - `element.getAttribute('href')` — получение относительного пути ссылки.

## 📝 Пошаговый план выполнения
1. Создать каталог `js/` и файл `js/main.js`.
2. Подключить `<script src="js/main.js" defer></script>` в `<head>` файла `index.html`.
3. В `js/main.js` написать функцию подсветки активного пункта меню:
   ```javascript
   function initNavigation() {
     const currentPath = window.location.pathname;
     const navLinks = document.querySelectorAll('.nav-link');
     
     navLinks.forEach(link => {
       const href = link.getAttribute('href');
       if (!href) return;
       
       if (currentPath.endsWith(href) || (currentPath.endsWith('/') && href.includes('index.html'))) {
         link.classList.add('active');
       }
     });
   }
   
   document.addEventListener('DOMContentLoaded', () => {
     initNavigation();
   });
   ```
4. Добавить в `css/style.css` стили для `.nav-link.active` (голубой фон `#eaf2ff`, синий текст `#007bff`).
