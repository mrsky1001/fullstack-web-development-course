## 💡 Теоретический минимум
1. **Flexbox-сетка (`.rooms-grid`):** `display: flex; flex-wrap: wrap; gap: 20px;`.
2. **Фиксация пропорций изображений:** Использование свойства `object-fit: cover` исключает растяжение и искажение фото при любых разрешениях.
3. **Обработка отсутствующих картинок:** Атрибут `onerror="this.src='img/no-image.svg'"` для безопасной загрузки заглушек.
4. **Компонентный подход к кнопкам:** Разделение базового класса `.btn` и модификаторов `.btn-primary`, `.btn-outline`.

## 📝 Пошаговый план выполнения
1. Открыть `index.html` и после `.hero-section` добавить секцию `<section class="popular-section">`.
2. Добавить заголовки секции:
   - `<h2 class="page-title">Популярные офисные комнаты</h2>`
   - `<p class="page-subtitle">Наиболее востребованные пространства с полным техническим оснащением</p>`
3. Сверстать контейнер `<div class="rooms-grid">` с 3 карточками `.room-card`:
   - Блок картинки `.card-img-wrap` + тег `<img>`.
   - Контент `.card-content`: название `.card-title`, список оснащения `.card-equipment`.
   - Футер карточки `.card-footer`: блок цены `.card-price` и ссылка-кнопка `.btn.btn-primary`.
4. Под сеткой карточек добавить блок `.center-action` с кнопкой «Больше офисов» (`.btn.btn-outline`).
5. В `css/style.css` добавить стили для кнопок, сетки и карточек с соблюдением фиксированной ширины и теней.
