## 🛠 Архитектура проекта и стек технологий
- **HTML5:** Семантическая разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>`).
- **CSS3:** Блочная модель, переменные `:root`, Flexbox, CSS Grid, Media Queries.
- **Палитра:** 4 основных цвета (Белый `#ffffff`, Темно-серый `#222222`, Акцентный синий `#007bff`, Светло-серый `#f8f9fa`).
- **JavaScript (Vanilla JS):** Манипуляции DOM, события, валидация форм, таймеры (`setInterval`), фильтрация/сортировка, калькулятор.

### Итоговая файловая структура:
```text
smart-office/
├── index.html               # Главная страница (шапка, слайдер, популярные комнаты, подвал)
├── pages/
│   ├── catalog.html         # Каталог офисов с поиском и сортировкой по цене
│   ├── booking.html         # Бронирование с калькулятором стоимости в реальном времени
│   ├── my-bookings.html     # Личный кабинет (список бронирований / заглушка)
│   ├── register.html        # Регистрация с клиентской валидацией
│   └── login.html           # Авторизация с проверкой логина/пароля
├── css/
│   └── style.css            # Единая таблица стилей (:root, компоненты, адаптив)
├── js/
│   ├── data.js              # Mock-данные офисных комнат и бронирований
│   └── main.js              # Вся логика портала (навигация, слайдер, валидация, расчет)
└── img/                     # Векторные SVG и растровые изображения
```

## ⏱ Тайминг экзамена (120 минут):
1. **00–15 мин:** Структура проекта, каркас `index.html`, семантическая шапка и подвал.
2. **15–30 мин:** Базовые стили `style.css`, Hero-блок, секция «Популярные офисные комнаты».
3. **30–50 мин:** Создание `data.js` и динамическая отрисовка каталога `pages/catalog.html`.
4. **50–70 мин:** Верстка форм `register.html` и `login.html`, клиентская валидация в `main.js`.
5. **70–85 мин:** Слайдер 100% ширины на главной (`setInterval` 3 сек + кнопки «‹» / «›» + индикаторы).
6. **85–105 мин:** Поиск и сортировка в каталоге, интерактивный калькулятор в `booking.html`.
7. **105–120 мин:** Страница `my-bookings.html`, сквозное тестирование и финальная проверка по ТЗ.
