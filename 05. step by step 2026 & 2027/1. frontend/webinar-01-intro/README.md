# Вебинар 1. Вводное занятие

## 📋 Описание занятия
- **Дисциплина:** ПИРИП (ПМ08. Разработка веб-приложения)
- **Целевая аудитория:** Студенты 1 курса колледжа
- **Тема:** Вводное занятие. Архитектура веб-приложения бронирования «СмартОфис»
- **Регламент итогового экзамена:** 2 академических часа (120 минут)

---

## 🎯 Цели и задачи
1. Ознакомиться с регламентом дисциплины и критериями оценивания итоговой работы.
2. Детально разобрать техническое задание (ТЗ) на разработку интернет-портала «СмартОфис».
3. Изучить структуру файлов и папок проекта без сторонних фреймворков.
4. Освоить дорожную карту (Roadmap) разработки проекта за 9 вебинаров.

---

## 🛠 Архитектура проекта и стек технологий
- **HTML5:** Семантическая разметка (header, nav, main, section, footer, article).
- **CSS3:** Блочная модель, переменные :root, Flexbox, CSS Grid, адаптивность (Media Queries).
- **Палитра:** 3 основных цвета (Белый, Черный, Голубой).
- **JavaScript (Vanilla JS):** Манипуляции DOM, события, валидация форм, таймеры (setInterval), фильтрация/сортировка, калькулятор.

### Итоговая файловая структура:
```text
smart-office/
├── index.html               # Главная страница (шапка, слайдер, популярные комнаты, подвал)
├── pages/
│   ├── catalog.html         # Каталог офисов с поиском и сортировкой по цене
│   ├── booking.html         # Бронирование с калькулятором стоимости в реальном времени
│   ├── my-bookings.html     # Личный кабинет (список бронирований / заглушка)
│   ├── register.html        # Регистрация с клиентской валидацией
│   └── login.html           # Авторизация с проверкой логина/пароля
├── css/
│   └── style.css            # Единая таблица стилей (:root, компоненты, адаптив)
├── js/
│   ├── data.js              # Mock-данные офисных комнат и бронирований
│   └── main.js              # Вся логика портала
└── img/                     # Векторные SVG-изображения (логотип, слайды, комнаты)
```

---

## ⏱ Тайминг экзамена (2 часа = 120 минут):
1. Структура проекта, каркас index.html, шапка и подвал (15 мин)
2. Стилизация шапки, подвала, секции популярных комнат (15 мин)
3. Создание data.js и динамическая отрисовка catalog.html (20 мин)
4. Формы register.html и login.html + клиентская валидация (20 мин)
5. Слайдер 800x400 на главной (setInterval + стрелки) (15 мин)
6. Поиск и сортировка в каталоге + калькулятор в booking.html (20 мин)
7. Страница my-bookings.html, финальное тестирование (15 мин)
