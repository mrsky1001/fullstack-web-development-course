## 📄 Общее техническое задание (ТЗ)

> **Проект:** Интернет-портал бронирования офисных комнат **«СмартОфис»**  
> **Цель:** Разработать фронтенд-часть интернет-портала для бронирования офисных комнат в коворкинге. Пользователи могут просматривать каталог офисных комнат, оформлять бронирования (через клиентскую логику) и взаимодействовать с элементами интерфейса. Взаимодействие с сервером не требуется, все данные хранятся статично.  
> **Время на выполнение:** 2 часа (120 минут).  
> **Технологический стек:** HTML5, CSS3, JavaScript (Vanilla JS).

### 1. Общие требования
1. **Семантика:** Использовать семантические теги (`<header>`, `<main>`, `<footer>`, `<nav>`, `<section>`, `<article>`).
2. **Изображения:** Исходные изображения должны быть стилизованы (растянуты на весь блок без искажения — `object-fit: cover`, центрированы).
3. **Адаптивность:** Корректное отображение на экранах с шириной от 1200px (адаптивность через Media Queries).
4. **Валидация форм:** В формах необходимо реализовать клиентскую валидацию: требовать от пользователя заполнения всех обязательных полей, подсвечивать ошибки и выводить уведомления.
5. **Единый стиль:** Шапка и подвал сайта должны быть унифицированы и использоваться на всех страницах.
6. **Цветовая палитра:** Подобрать цветовую гамму из 3–5 основных цветов (белый, черный/темно-серый, акцентный синий `#007bff`, фоновый светло-серый `#f8f9fa`).
7. **Верстка:** Использовать современные методы верстки Flexbox и Grid.

### 2. Требования к страницам сайта

#### 2.1. Главная страница (`index.html`)
- **Шапка:** Логотип (SVG), название «СмартОфис». Навигация: «Главная», «Каталог», «Войти» (статичные ссылки). Для имитации авторизации при клике на «Войти» перенаправлять на `login.html`.
- **Слайдер:** Блок с четырьмя изображениями (100% ширины контейнера, высота 400px). Реализовать на Vanilla JS (автоматическая смена каждые 3 секунды + ручное управление стрелками и индикаторами).
- **Секция «Популярные офисные комнаты»:** Статичный блок из трех карточек (изображение 300x200px, название, оснащение, цена). Кнопка «Больше офисов» ведет на `catalog.html`.
- **Подвал:** Контактная информация (email, телефон), копирайт.

#### 2.2. Страница регистрации (`pages/register.html`)
- **Форма:** Поля: Логин, Пароль, Подтверждение пароля, ФИО, Email, Телефон.
- **Логика:** При нажатии кнопки «Зарегистрироваться» валидировать данные на стороне клиента:
  - При успехе — выводить всплывающее сообщение `«Пользователь зарегистрирован успешно!»`.
  - При ошибке (незаполненные поля, несовпадение паролей, неверный формат) — выделять поля красным цветом (`.is-invalid`) и выводить сообщение об ошибке.

#### 2.3. Страница авторизации (`pages/login.html`)
- **Форма:** Поля «Логин» и «Пароль».
- **Логика:** Кнопка «Войти» должна проверять корректность (статические тестовые данные в JS). При ошибке выводить текст `«Неверный логин или пароль»`. При успехе — перенаправлять на главную или каталог.

#### 2.4. Страница каталога (`pages/catalog.html`)
- **Отображение:** Использовать массив JavaScript-объектов (`data.js`) для динамической отрисовки карточек офисов.
- **Фильтрация и поиск:** Текстовое поле для поиска по названию офиса.
- **Сортировка:** Кнопки / выпадающий список сортировки по цене (по возрастанию / по убыванию). При изменении фильтров и сортировки массив фильтруется и DOM-элементы перерисовываются.
- **Бронирование:** Кнопка «Забронировать» на карточке ведет на страницу бронирования `booking.html` с предвыбором офиса или в форму.

#### 2.5. Страница бронирования (`pages/booking.html`)
- **Форма:** Выбор комнаты (`<select>`), выбор даты (`<input type="date">`), количество часов (`<input type="number">`), комментарий (`<textarea>`).
- **Калькулятор стоимости:** Рассчитывать общую стоимость на JS в реальном времени (`цена за час × количество часов`) и выводить на экран.
- **Логика:** При нажатии кнопки «Забронировать» валидировать форму и выводить всплывающее сообщение: `«Бронирование создано! Номер заявки: №[случайный номер]»`.

#### 2.6. Страница «Мои бронирования» (`pages/my-bookings.html`)
- **Отображение:** Отобразить список бронирований пользователя из массива mock-данных (`data.js`).
- **Пустое состояние:** Если список пуст, выводить информационное сообщение: `«У вас пока нет бронирований»` и кнопку перехода в каталог.

### 3. Структура проекта
```text
smart-office/
├── index.html               # Главная страница (шапка, слайдер, популярные комнаты, подвал)
├── pages/
│   ├── register.html        # Страница регистрации с валидацией
│   ├── login.html           # Страница авторизации
│   ├── catalog.html         # Страница каталога (поиск, сортировка, mock-данные)
│   ├── booking.html         # Страница бронирования с живым калькулятором стоимости
│   └── my-bookings.html     # Страница личного кабинета (список бронирований)
├── css/
│   └── style.css            # Единая таблица стилей
├── js/
│   ├── main.js              # Основная логика, слайдер, валидация, калькулятор
│   └── data.js              # Массив mock-данных (офисы и бронирования)
└── img/                     # Векторная графика и изображения
```

## 📁 Структура каждого вебинара
Каждый каталог вебинара (начиная со 2-го) содержит две версии проекта:
1. `basic/` — компактный, чистый код без комментариев для быстрой демонстрации преподавателем на занятии (укладывается в 2 часа).
2. `with-comments/` — подробная комментированная версия для самостоятельного изучения студентами.
3. `README.md` — подробные подзадачи из ТЗ, теория, пошаговые инструкции и критерии приемки.
