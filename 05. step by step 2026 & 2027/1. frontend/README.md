# 🎓 Курс «Веб-разработка» — 1 семестр: Пошаговая разработка итогового проекта «СмартОфис»

## 📋 О курсе
- **Дисциплина:** ПИРИП (ПМ08. Разработка веб-приложения)
- **Уровень:** 1 курс колледжа (с нуля)
- **Итоговый проект:** Интернет-портал бронирования офисных комнат **«СмартОфис»**
- **Формат:** 9 пошаговых вебинаров
- **Целевое время разработки преподавателем:** 2 академических часа (120 минут)
- **Стек технологий:** HTML5, CSS3 (простые стили, светлая тема, палитра: белый, черный, голубой), JavaScript (Vanilla JS).

## 📁 Структура каждого вебинара
Каждый каталог вебинара (начиная со 2-го) содержит две версии проекта:
1. `basic/` — компактный, чистый код без комментариев для быстрой демонстрации преподавателем на занятии (укладывается в 2 часа).
2. `with-comments/` — подробная комментированная версия для самостоятельного изучения студентами.
3. `README.md` — краткий конспект занятия: цели, теория, пошаговые действия.
