# Вебинар 9. Итоговая сборка и ревью проекта: Страница «Мои бронирования» и приемка по ТЗ

## 📋 Описание занятия
- **Дисциплина:** ПИРИП (ПМ08. Разработка веб-приложения)
- **Уровень:** 1 курс колледжа
- **Тема:** Страница «Мои бронирования», финальная интеграция 6 страниц, тестирование всех сценариев ТЗ и предэкзаменационный чек-лист.

---

## 🎯 Подзадачи из общего ТЗ на этот вебинар

| № | Подзадача | Описание требований ТЗ |
|---|---|---|
| 9.1 | **Mock-данные бронирований** | Добавление массива `bookingsData` в `js/data.js` (поля: `id`, `roomName`, `date`, `hours`, `totalPrice`, `status`). |
| 9.2 | **Верстка страницы `pages/my-bookings.html`** | Унифицированная шапка, подвал, заголовок «Мои бронирования», контейнер списка `#myBookingsList`. |
| 9.3 | **Динамический рендеринг бронирований** | Функция `renderMyBookings()`: генерация карточек/таблицы существующих бронирований из `bookingsData`. |
| 9.4 | **Обработка пустого состояния** | Если массив пуст (`bookingsData.length === 0`), отображать блок с текстом `«У вас пока нет бронирований»` и кнопкой перехода в каталог. |
| 9.5 | **Сквозное тестирование по всем пунктам ТЗ** | Проверка всех 6 страниц, ссылок, валидации, слайдера, калькулятора и консоли браузера на отсутствие ошибок. |

---

## 💡 Теоретический минимум
1. **Условный рендеринг (Conditional Rendering):** Проверка длины массива `data.length === 0` для показа состояния заглушки (Empty State).
2. **Форматирование данных:** Вывод статусов («Подтверждено», «Ожидает оплаты») с цветовыми бейджами.
3. **Финальный аудит качества верстки:** Проверка валидности HTML, отсутствия ломаных ссылок (404), поведения картинок при сбоях (`onerror`).

---

## 📝 Пошаговый план выполнения
1. В `js/data.js` добавить массив тестовых бронирований:
   ```javascript
   const bookingsData = [
     {
       id: "BK-10492",
       roomName: "Мини-офис Focus",
       date: "2026-09-01",
       hours: 3,
       totalPrice: 1350,
       status: "Подтверждено"
     },
     {
       id: "BK-10518",
       roomName: "Конференц-зал Alpha",
       date: "2026-09-03",
       hours: 2,
       totalPrice: 2400,
       status: "Ожидает подтверждения"
     }
   ];
   ```
2. Создать страницу `pages/my-bookings.html`:
   - Подключить общие стили и скрипты.
   - Добавить блок `<div id="myBookingsList" class="bookings-list"></div>`.
3. В `js/main.js` написать функцию `renderMyBookings()`:
   ```javascript
   function renderMyBookings() {
     const container = document.getElementById('myBookingsList');
     if (!container) return;
     
     if (!bookingsData || bookingsData.length === 0) {
       container.innerHTML = `
         <div class="empty-state">
           <p>У вас пока нет бронирований</p>
           <a href="catalog.html" class="btn btn-primary" style="margin-top: 15px;">Перейти в каталог</a>
         </div>
       `;
       return;
     }
     
     container.innerHTML = bookingsData.map(b => `
       <div class="booking-card">
         <div class="booking-header">
           <span class="booking-number">№ ${b.id}</span>
           <span class="badge ${b.status === 'Подтверждено' ? 'badge-success' : 'badge-warning'}">${b.status}</span>
         </div>
         <div class="booking-body">
           <h4>${b.roomName}</h4>
           <p>Дата: <strong>${b.date}</strong> | Длительность: <strong>${b.hours} ч.</strong></p>
           <p class="booking-price">Итого: <strong>${b.totalPrice} ₽</strong></p>
         </div>
       </div>
     `).join('');
   }
   ```
4. Выполнить проверку по **Экзаменационному чек-листу**.
