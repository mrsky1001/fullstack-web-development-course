# 📊 Курс: Базы данных и SQL

## 📋 Описание курса

Этот модуль посвящён основам работы с **реляционными базами данных** и языком **SQL**. Вы научитесь проектировать базы данных, писать запросы и эффективно работать с данными.

## 🎯 Цели курса

После прохождения курса вы сможете:

- Понимать принципы работы **реляционных баз данных**
- Проектировать базы данных с помощью **ER-диаграмм**
- Устанавливать и настраивать **MySQL**
- Писать SQL-запросы для **CRUD-операций**
- Использовать **JOIN**, **GROUP BY** и агрегатные функции
- Оптимизировать запросы с помощью **индексов**

## 📖 Глоссарий

| Термин | Определение |
|--------|-------------|
| **СУБД** | Система управления базами данных |
| **SQL** | Structured Query Language — язык запросов |
| **Таблица** | Структура для хранения данных в строках и столбцах |
| **Запись (Row)** | Одна строка в таблице |
| **Поле (Column)** | Один столбец в таблице |
| **Primary Key** | Уникальный идентификатор записи |
| **Foreign Key** | Ссылка на запись в другой таблице |
| **JOIN** | Объединение данных из нескольких таблиц |
| **Индекс** | Структура для ускорения поиска |
