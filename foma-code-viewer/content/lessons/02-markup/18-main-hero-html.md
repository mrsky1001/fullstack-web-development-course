# Разметка основной части (Main)

Шапка есть. Теперь мы переходим к контенту страницы.

По правилам семантики, всё уникальное содержимое страницы должно находиться внутри тега `<main>`. Это помогает поисковикам понимать, где заканчиваются сквозные элементы (шапка/подвал) и начинается суть.

Сразу под закрывающим тегом шапки `</header>` мы создадим `<main class="main">`.

Внутри `<main>` мы снова должны использовать нашу центрирующую обертку `<div class="container">`, иначе текст размажется по краям!
Внутри контейнера мы создадим секцию (отдельную смысловую область) через тег `<section class="hero-section">`. Термин *Hero Section* (или просто *Hero*) означает самый первый, главный блок на сайте, который видит пользователь.

## 🛠 Задание

В файле `index.html` сразу после `</header>` создайте:
1. Тег `<main class="main">`
2. Внутри него — `<div class="container">`
3. И внутри контейнера пустую секцию `<section class="hero-section"></section>`

```html:start
  </header>
  
</body>
```

```html:solution
  </header>

  <main class="main">
    <div class="container">
      <section class="hero-section">
        
      </section>
    </div>
  </main>
</body>
```
