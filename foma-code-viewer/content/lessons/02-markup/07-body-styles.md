# Стили для тела сайта (body)

Следующий шаг — задать глобальные стили для всей страницы. Так как весь видимый контент лежит внутри тега `<body>`, мы стилизуем именно его. Эти стили будут наследоваться всеми элементами внутри.

## Шрифты и цвета
Мы подключили крутой шрифт Inter, теперь нужно сказать браузеру использовать его!

Добавим следующие свойства:
- `font-family: 'Inter', sans-serif;` — сначала браузер попытается использовать Inter. Если по какой-то причине шрифт не загрузится (например, нет интернета), он включит любой системный шрифт без засечек (`sans-serif`).
- `color: #222222;` — делаем текст не абсолютно черным (`#000`), а темно-серым. Это приятнее для глаз при чтении с экрана.
- `background-color: #ffffff;` — явно указываем белый фон.
- `line-height: 1.5;` — высота строки (межстрочный интервал). Значение 1.5 означает, что высота строки будет в полтора раза больше размера шрифта. Это золотой стандарт читаемости.

## 🛠 Задание

Добавьте селектор `body` и пропишите в нём эти четыре свойства.

```css:start
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

```

```css:solution
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: 'Inter', sans-serif;
  color: #222222;
  background-color: #ffffff;
  line-height: 1.5;
}
```
