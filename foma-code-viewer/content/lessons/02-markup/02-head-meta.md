# Настройки документа (head и meta)

Внутри тега `<html>` страница всегда делится на две большие части: `<head>` (голова) и `<body>` (тело).

В этом шаге мы поговорим о "голове" — теге `<head>`.
Всё, что мы напишем внутри `<head>`, **не будет видно** обычным посетителям на самом сайте. Здесь хранятся служебные настройки, инструкции для браузера и поисковиков.

## Тег <meta>
Тег `<meta>` (от слова "метаданные", то есть данные о данных) — это непарный тег, который используется для задания скрытых настроек. У него нет закрывающей пары.

Мы добавим две критически важные настройки:
1. `<meta charset="UTF-8">` — задает **кодировку**. UTF-8 поддерживает все языки мира. Если этого не сделать, вместо русских букв пользователи могут увидеть странные "кракозябры" (иероглифы).
2. `<meta name="viewport" content="width=device-width, initial-scale=1.0">` — магическая строка, которая заставляет сайт **адаптироваться под мобильные телефоны**. Без неё телефон попытается показать весь огромный сайт целиком, сделав текст микроскопическим.

## 🛠 Задание

Внутри тега `<html>` (между открывающим и закрывающим) добавьте тег `<head>`. Внутрь `<head>` поместите два описанных выше тега `<meta>`.

```html:start
<!DOCTYPE html>
<html lang="ru">

</html>
```

```html:solution
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
</html>
```
