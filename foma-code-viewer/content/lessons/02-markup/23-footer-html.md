# Разметка Подвала (Footer)

Любой хороший сайт заканчивается Подвалом. Там обычно находится копирайт, ссылки на документы и контакты.

Для подвала есть специальный семантический тег `<footer>`. Мы разместим его **после** закрывающего тега `</main>`, так как подвал не является основной контентной частью.

Внутри подвала мы снова создадим наш центрирующий `<div class="container footer-container">`.

Внутри контейнера будут две колонки (два блока `<div>`):
1. `<div class="footer-info">` — с текстом о защите прав.
2. `<div class="footer-contacts">` — с email и телефоном. Обратите внимание: для email мы используем ссылку вида `mailto:info@...`, а для телефона `tel:+7...`. Это сделает их кликабельными, и на телефоне сразу откроется набор номера!

## 🛠 Задание

В `index.html` сразу после `</main>` добавьте этот код. Скопируйте его из решения ниже, если не хотите набирать текст вручную.

```html:start
    </div>
  </main>

</body>
```

```html:solution
    </div>
  </main>

  <footer class="footer">
    <div class="container footer-container">
      <div class="footer-info">
        <p><strong>СмартОфис</strong> — Сервис бронирования офисных комнат</p>
        <p>© 2026 СмартОфис. Все права защищены.</p>
      </div>
      <div class="footer-contacts">
        <p>Email: <a href="mailto:info@smartoffice.ru">info@smartoffice.ru</a></p>
        <p>Телефон: <a href="tel:+78005553535">+7 (800) 555-35-35</a></p>
      </div>
    </div>
  </footer>
</body>
```
