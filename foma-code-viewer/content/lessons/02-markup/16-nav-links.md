# Стили ссылок и псевдоклассы

Список выстроился в ряд, но сами ссылки все еще синие и с подчеркиванием. Давайте приведем класс `.nav-link` в порядок!

- `text-decoration: none;` — убираем подчеркивание.
- `color: #222222;` — делаем текст темно-серым.
- `padding: 8px 14px;` — добавляем внутренние отступы, чтобы ссылка стала "побольше" и по ней было легче кликнуть.
- `border-radius: 4px;` — немного скругляем углы (мы этого не увидим, пока не добавим фон при наведении).
- `font-size: 14px;` и `font-weight: 500;` — делаем текст чуть мельче, но жирнее, чтобы он аккуратно смотрелся в шапке.

## Псевдокласс :hover
Чтобы сайт казался живым, элементы должны реагировать на наведение мыши. В CSS для этого используется псевдокласс `:hover`.
Он пишется слитно после класса: `.nav-link:hover`.

Свойства внутри `:hover` применяются **только тогда, когда курсор мыши находится над элементом**. Мы поменяем цвет текста на синий (`#007bff`) и добавим светло-синий фон (`#eaf2ff`).

## 🛠 Задание

В файле `style.css` добавьте селекторы `.nav-link` и `.nav-link:hover` с описанными свойствами. После этого наведите мышку на ссылки в окне результата!

```css:start
.nav-list {
  display: flex;
  list-style: none;
  gap: 12px;
  align-items: center;
}

```

```css:solution
.nav-list {
  display: flex;
  list-style: none;
  gap: 12px;
  align-items: center;
}

.nav-link {
  text-decoration: none;
  color: #222222;
  padding: 8px 14px;
  border-radius: 4px;
  font-weight: 500;
  font-size: 14px;
}

.nav-link:hover {
  color: #007bff;
  background-color: #eaf2ff;
}
```
