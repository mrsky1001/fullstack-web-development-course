# Сброс стилей браузера

Отлично, каркас готов! Переходим во вкладку **style.css**.

Если вы просто начнете писать HTML, браузер по умолчанию добавит свои собственные отступы вокруг страницы и элементов. Из-за этого дизайн может «поехать». Поэтому первое правило любого CSS-файла — это **сброс стилей** (Reset).

## Селектор звездочка (*)
Символ `*` (звездочка) в CSS означает «Выбрать абсолютно все элементы на странице».

Мы зададим всем элементам три важных правила:
1. `margin: 0;` — убираем все внешние отступы по умолчанию.
2. `padding: 0;` — убираем все внутренние отступы по умолчанию.
3. `box-sizing: border-box;` — очень важное правило! Оно говорит браузеру: "Если я задал блоку ширину 100px, а потом добавил внутренний отступ 10px, общая ширина блока все равно должна остаться 100px". Без этого правила блоки бы раздувались и ломали верстку.

## 🛠 Задание

В файле `style.css` напишите селектор `*` и добавьте три свойства, описанные выше.

*(В этом шаге и далее мы не будем показывать HTML-код в решении, если он не меняется, чтобы вы могли сфокусироваться на CSS).*

```css:start
/* Наш CSS пока пуст */
```

```css:solution
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```
