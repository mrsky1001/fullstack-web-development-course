# Кнопка входа

Почти готово! Но ссылка "Войти" должна выделяться. Она должна выглядеть как настоящая кнопка.
Обратите внимание, что в HTML у ссылки "Войти" два класса: `class="nav-link nav-btn"`. 

Это значит, что она **уже получила** все свойства от `.nav-link` (отступы, убранное подчеркивание). Теперь нам нужно написать свойства для `.nav-btn`, которые *переопределят* её внешний вид. Это и называется "Каскадность" (С) в CSS!

## 1. Стили для кнопки
Для `.nav-btn`:
- `background-color: #007bff;` — заливаем кнопку фирменным синим цветом.
- `color: #ffffff;` — текст делаем белым, чтобы его было видно на синем фоне.
- `font-weight: 600;` — делаем текст еще жирнее.

## 2. Эффект наведения
Так как мы поменяли фон кнопки, стандартный эффект `.nav-link:hover` (светло-синий фон) ей больше не подходит.
Напишем новый `.nav-btn:hover`:
- `background-color: #0056b3;` — при наведении кнопка будет становиться темно-синей.
- `color: #ffffff;` — текст оставляем белым.

## 🛠 Задание
Добавьте эти два селектора (`.nav-btn` и `.nav-btn:hover`) в файл стилей. Поздравляю, шапка сайта полностью готова!

```css:start
.nav-link:hover {
  color: #007bff;
  background-color: #eaf2ff;
}

```

```css:solution
.nav-link:hover {
  color: #007bff;
  background-color: #eaf2ff;
}

.nav-btn {
  background-color: #007bff;
  color: #ffffff;
  font-weight: 600;
}

.nav-btn:hover {
  background-color: #0056b3;
  color: #ffffff;
}
```
