# Название вкладки и иконка

Продолжаем наполнять наш `<head>` полезными настройками! Когда вы открываете любой сайт, вы видите его название на вкладке браузера, а рядом — маленькую иконку (Favicon).

## 1. Название вкладки (<title>)
За текст на вкладке браузера отвечает парный тег `<title>`.
Кроме того, именно этот текст пользователи видят в результатах поиска Яндекса или Google, когда ищут ваш сайт. Поэтому он должен быть осмысленным!

Наш заголовок: `СмартОфис — Бронирование офисных комнат`.

## 2. Иконка вкладки (favicon)
Чтобы добавить маленькую картинку на вкладку, используется непарный тег `<link>`.
Тег `<link>` нужен для связывания (от слова *link* — связь) нашего HTML-файла с внешними ресурсами.

Его атрибуты:
- `rel="icon"` (relation) — говорит браузеру, что это именно иконка.
- `type="image/svg+xml"` — формат нашей иконки (векторный SVG).
- `href="img/logo.svg"` — путь к файлу с картинкой.

## 🛠 Задание

Добавьте теги `<title>` и `<link>` внутрь секции `<head>` под нашими мета-тегами.

```html:start
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

</head>
</html>
```

```html:solution
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>СмартОфис — Бронирование офисных комнат</title>
  <link rel="icon" type="image/svg+xml" href="img/logo.svg">
</head>
</html>
```
