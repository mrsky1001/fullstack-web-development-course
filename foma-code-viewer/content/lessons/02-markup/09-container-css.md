# Что такое Контейнер?

Если вы посмотрите на любой крупный сайт (например, ВКонтакте или Кинопоиск), вы заметите, что контент не размазывается по краям вашего широкого монитора. Он всегда собран в аккуратную колонку по центру. 

Для этого в вебе используется паттерн "Контейнер". Мы будем создавать пустые невидимые коробки (`<div>`) с классом `.container` и класть в них весь контент, чтобы он выравнивался по центру.

Так как контейнеров на странице будет много (в шапке, в подвале, в основной части), мы напишем для него стиль один раз и будем переиспользовать!

## Стилизуем класс .container

Чтобы стилизовать HTML-элемент не по имени тега (как мы делали с `body`), а по его "имени" (классу), в CSS перед именем класса ставится **точка**.

Добавим:
- `width: 1200px;` — жесткая ширина контентной части сайта.
- `margin: 0 auto;` — магия центрирования! `0` означает, что сверху и снизу отступов нет, а `auto` говорит браузеру: "Автоматически рассчитай одинаковые отступы слева и справа". В результате блок встает ровно по центру экрана.
- `padding: 0 15px;` — внутренние отступы по 15 пикселей слева и справа. Они нужны, чтобы текст не прилипал вплотную к краям экрана, если окно браузера станет меньше 1200px.

## 🛠 Задание

В файле `style.css` под стилями `body` создайте новый селектор `.container` (не забудьте точку!) и добавьте туда эти три свойства.

```css:start
body {
  font-family: 'Inter', sans-serif;
  color: #222222;
  background-color: #ffffff;
  line-height: 1.5;
  display: flex;
  flex-direction: column;
  min-height: 100vh;
  min-width: 1200px;
}

```

```css:solution
body {
  font-family: 'Inter', sans-serif;
  color: #222222;
  background-color: #ffffff;
  line-height: 1.5;
  display: flex;
  flex-direction: column;
  min-height: 100vh;
  min-width: 1200px;
}

.container {
  width: 1200px;
  margin: 0 auto;
  padding: 0 15px;
}
```
