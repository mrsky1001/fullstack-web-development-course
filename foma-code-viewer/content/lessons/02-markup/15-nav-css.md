# Стилизация списка навигации

Вы добавили меню, но выглядит оно ужасно: это просто вертикальный список с точками. Пора применить магию CSS!

Мы стилизуем сам список — класс `.nav-list`.

- Чтобы выстроить пункты в горизонтальный ряд (а не столбиком), мы снова используем супер-оружие: `display: flex;`.
- `align-items: center;` — выравнивает пункты строго по одной горизонтальной линии.
- `gap: 12px;` — задает расстояние (отступы) между пунктами списка.
- `list-style: none;` — это очень важное свойство. Оно **удаляет черные точки** (маркеры) у списка.

## 🛠 Задание

В файле `style.css` добавьте селектор `.nav-list` и пропишите в нём эти четыре свойства.

```css:start
.logo-icon {
  width: 32px;
  height: 32px;
}

```

```css:solution
.logo-icon {
  width: 32px;
  height: 32px;
}

.nav-list {
  display: flex;
  list-style: none;
  gap: 12px;
  align-items: center;
}
```
