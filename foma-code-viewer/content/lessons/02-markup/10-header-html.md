# Разметка шапки сайта (Header)

Фух, с базой покончено! Мы переходим к самому вкусному — верстке видимых блоков сайта. И начинаем мы, конечно же, сверху — с шапки сайта.

Для семантически правильной верстки (чтобы поисковики радовались) шапка сайта оборачивается в специальный тег `<header>`.

Мы также добавим к этому тегу атрибут `class="header"`, чтобы мы могли легко стилизовать его в CSS. 

А чтобы контент шапки не размазался по краям экрана, мы внутрь `header` положим наш универсальный невидимый ящик — `<div class="container">`.

Мы дадим этому диву сразу два класса через пробел: `class="container header-container"`.
- `container` — отцентрирует блок.
- `header-container` — понадобится нам позже, чтобы расположить элементы шапки по горизонтали.

## 🛠 Задание

Перейдите во вкладку `index.html`. Внутри тега `<body>` напишите:
1. Тег `<header class="header">`.
2. Внутри него — `<div class="container header-container"></div>`.
3. Не забудьте закрыть `</header>`.

```html:start
<body>

</body>
```

```html:solution
<body>
  <header class="header">
    <div class="container header-container">
      
    </div>
  </header>
</body>
```
