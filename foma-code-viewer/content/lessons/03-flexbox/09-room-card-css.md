# Стили для карточки

Мы создали `<div>` для карточки, но он пустой и невидимый. Давайте зададим ему габариты и внешний вид в `style.css`.

Мы хотим, чтобы карточка выглядела как белый прямоугольник со скругленными углами и тонкой серой рамкой.

## Свойства .room-card
- `width: 373px;` — жестко задаем ширину (это ровно треть от нашего контейнера в 1200px минус отступы между карточками).
- `border: 1px solid #dddddd;` — тонкая серая рамка.
- `border-radius: 6px;` — скругляем углы.
- `background-color: #ffffff;` — белый фон (чтобы карточка выделялась, если фон сайта изменится).
- `display: flex; flex-direction: column;` — делаем саму карточку флекс-контейнером! Это нужно для того, чтобы подвал с ценой всегда прижимался к низу карточки.
- `overflow: hidden;` — **ОЧЕНЬ ВАЖНОЕ СВОЙСТВО**. Если мы положим внутрь карточки квадратную картинку, её острые углы вылезут за пределы наших скругленных углов рамки. Это свойство буквально означает: "Обрезать всё, что вылезает за пределы рамки".

## 🛠 Задание

В файле `style.css` (перед подвалом) создайте комментарий `/* Сетка карточек комнат */` и добавьте селектор `.room-card` с этими свойствами.

```css:start
.btn-icon:hover {
  background-color: #eaf2ff;
  color: #0056b3;
  border-color: #0056b3;
}

```

```css:solution
.btn-icon:hover {
  background-color: #eaf2ff;
  color: #0056b3;
  border-color: #0056b3;
}

/* Сетка карточек комнат */
.room-card {
  width: 373px;
  border: 1px solid #dddddd;
  border-radius: 6px;
  overflow: hidden;
  background-color: #ffffff;
  display: flex;
  flex-direction: column;
}
```
