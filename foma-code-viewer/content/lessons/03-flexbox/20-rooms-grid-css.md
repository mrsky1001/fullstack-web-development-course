# Включаем сетку Flexbox

Вы добавили три карточки, но они выстроились вертикально в длинную "колбасу", прилипнув к подзаголовку.

Чтобы выстроить их в сетку, мы применим Flexbox к их общей обертке — классу `.rooms-grid`. 

## Свойства .rooms-grid
- `display: flex;` — карточки выстроятся в один ряд.
- `flex-wrap: wrap;` — **Критически важное свойство**. Оно разрешает элементам переноситься на новую строку, если они не помещаются в один ряд по ширине.
- `gap: 20px;` — идеальное расстояние между карточками (как по горизонтали, так и по вертикали).
- `margin-top: 30px;` и `margin-bottom: 30px;` — отступы сверху (от заголовков) и снизу.

## 🛠 Задание

В файле `style.css` найдите селектор `.room-card` и добавьте **ПЕРД НИМ** селектор `.rooms-grid` с этими свойствами.

*(Мы добавляем его перед `.room-card`, чтобы сохранить логику: сначала родитель, потом дети).*

```css:start
/* Сетка карточек комнат */

.room-card {
```

```css:solution
/* Сетка карточек комнат */
.rooms-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
  margin-top: 30px;
  margin-bottom: 30px;
}

.room-card {
```
