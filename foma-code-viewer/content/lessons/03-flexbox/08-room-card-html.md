# Скелет карточки комнаты

Сначала мы полностью, шаг за шагом, сверстаем **одну карточку**. Когда она будет готова и красива, мы просто скопируем её несколько раз!

Первый шаг — создать саму карточку. Это обычный блок `<div>`, которому мы дадим класс `.room-card`.

Вся карточка — это единый смысловой блок, внутри которого потом появятся картинка, название, цена и кнопки.

## 🛠 Задание

Внутри созданной вами обертки `.rooms-grid` добавьте новую пустую карточку:
`<div class="room-card"></div>`.

```html:start
        <div class="rooms-grid">
          
        </div>
```

```html:solution
        <div class="rooms-grid">
          <div class="room-card">
            
          </div>
        </div>
```
