# Добавляем картинку комнаты

Любая привлекательная карточка начинается с сочной фотографии. 

В верстке редко вставляют тег `<img>` напрямую. Обычно картинку оборачивают в специальный блок-контейнер (`.card-img-wrap`), чтобы жестко контролировать её размеры.

Кроме того, мы хотим, чтобы по клику на картинку пользователь переходил на страницу комнаты, поэтому мы обернем картинку в тег ссылки `<a>`.

## Обработка ошибок (onerror)
Обратите внимание на атрибут `onerror` у картинки. Это маленький JavaScript-трюк. Если браузер не сможет загрузить основную картинку (например, `img/room-1.jpg`), он автоматически подставит заглушку `img/no-image.svg`.

## 🛠 Задание

Внутри вашего `.room-card` добавьте обертку, ссылку и картинку!

```html:start
          <div class="room-card">
            
          </div>
```

```html:solution
          <div class="room-card">
            <div class="card-img-wrap">
              <a href="pages/catalog.html">
                <img src="img/room-1.jpg" alt="Мини-офис Focus" class="card-img" onerror="this.src='img/no-image.svg'">
              </a>
            </div>
          </div>
```
