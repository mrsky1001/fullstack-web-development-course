# Сетка комнат (Обертка)

Переходим к главному блюду — карточкам комнат!

Обычно карточки не болтаются на сайте по одной, они выстроены в красивую сетку (Grid). Чтобы браузер понимал, что карточки связаны друг с другом и их нужно выстраивать в ряд, нам нужна обертка (родительский элемент).

Мы создадим пустой `<div>` и дадим ему класс `.rooms-grid`. 
В следующих шагах мы превратим этот див во flex-контейнер, а все карточки, которые мы положим внутрь, станут flex-элементами.

## 🛠 Задание

В файле `index.html` сразу под абзацем с подзаголовком добавьте обертку для карточек:
`<div class="rooms-grid"></div>`.

```html:start
      <section class="popular-section">
        <h2 class="page-title">Популярные офисные комнаты</h2>
        <p class="page-subtitle">Наиболее востребованные пространства с полным техническим оснащением</p>
        
      </section>
```

```html:solution
      <section class="popular-section">
        <h2 class="page-title">Популярные офисные комнаты</h2>
        <p class="page-subtitle">Наиболее востребованные пространства с полным техническим оснащением</p>

        <div class="rooms-grid">
          
        </div>
      </section>
```
