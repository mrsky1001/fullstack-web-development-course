# Базовый класс для кнопок (.btn)

Прежде чем верстать карточки комнат, нам нужно подготовить **Систему кнопок**. В наших карточках будут кнопки «Забронировать» и «Подробнее».

Кнопки на сайтах часто бывают разными по цвету, но одинаковыми по форме (одинаковые отступы, шрифт, скругление углов). Поэтому мы создадим один базовый класс `.btn`, который будет задавать **форму** любой кнопке на сайте.

## Свойства формы (.btn)
- `display: inline-block;` — позволяет кнопке (даже если это ссылка `<a>`) принимать отступы (padding) и вести себя как блок, но при этом не занимать всю ширину экрана.
- `padding: 8px 16px;` — внутренние отступы: 8px сверху и снизу, 16px по бокам.
- `font-size: 14px;` и `font-weight: 600;` — стиль текста.
- `border-radius: 4px;` — скругление углов.
- `border: 1px solid transparent;` — мы заранее добавляем прозрачную рамку. Это нужно для того, чтобы кнопки с рамкой и без рамки были одинаковой высоты.
- `cursor: pointer;` — при наведении курсор будет превращаться в "руку с пальцем", даже если кнопка не является ссылкой.
- `text-decoration: none;` — убираем подчеркивание.
- `text-align: center;` — центрируем текст.

## 🛠 Задание
В `style.css` (в самом низу) добавьте комментарий `/* Кнопки */` и создайте класс `.btn` с описанными свойствами. Мы пока не увидим изменений, так как еще не применили этот класс в HTML!

```css:start
.footer-contacts a {
  color: #007bff;
  text-decoration: none;
}

```

```css:solution
.footer-contacts a {
  color: #007bff;
  text-decoration: none;
}

/* Кнопки */
.btn {
  display: inline-block;
  padding: 8px 16px;
  font-size: 14px;
  font-weight: 600;
  border-radius: 4px;
  border: 1px solid transparent;
  cursor: pointer;
  text-decoration: none;
  text-align: center;
}
```
