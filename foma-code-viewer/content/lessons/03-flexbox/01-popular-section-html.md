# Разметка новой секции

Добро пожаловать в третий вебинар! Сегодня мы сверстаем красивую сетку с карточками комнат и создадим набор кнопок.

Любой крупный блок на сайте выделяется в отдельную секцию `<section>`. Мы разместим её под нашим главным экраном (сразу после закрывающего тега `</section>` для `hero-section`).

Внутри новой секции мы добавим стандартные для всех страниц сайта заголовок (`h2`) и подзаголовок (`p`).

## 🛠 Задание

В файле `index.html` найдите закрывающий тег `</section>` (который относится к `hero-section`). Сразу под ним добавьте новую секцию:

1. Создайте `<section class="popular-section">`.
2. Внутри добавьте заголовок второго уровня `<h2 class="page-title">Популярные офисные комнаты</h2>`.
3. Под ним добавьте абзац `<p class="page-subtitle">Наиболее востребованные пространства с полным техническим оснащением</p>`.

```html:start
        </div>
      </section>
      
    </div>
  </main>
```

```html:solution
        </div>
      </section>

      <section class="popular-section">
        <h2 class="page-title">Популярные офисные комнаты</h2>
        <p class="page-subtitle">Наиболее востребованные пространства с полным техническим оснащением</p>
      </section>
    </div>
  </main>
```
