# Объекты в JavaScript

Массив — это список. Но как описать сложную сущность (например, комнату), у которой есть название, цена и вместимость?

Для этого используются **объекты** `{}`.
Объект состоит из пар "Ключ: Значение".

- `id: 'focus-1'` (строка текста берется в кавычки)
- `pricePerHour: 450` (числа пишутся без кавычек)
- `isPopular: true` (булево значение — истина/ложь)

## 🛠 Задание

Добавьте первый объект (Мини-офис Focus) внутрь вашего массива `OFFICE_ROOMS`.

```js:start
// СмартОфис — База данных офисных комнат и бронирований
const OFFICE_ROOMS = [

];
```

```js:solution
// СмартОфис — База данных офисных комнат и бронирований
const OFFICE_ROOMS = [
  {
    id: 'focus-1',
    title: 'Мини-офис Focus',
    pricePerHour: 450,
    capacity: '1-2 человека',
    area: '12 м²',
    description: 'Идеальное тихое пространство для индивидуальной работы, важных звонков и глубокой концентрации.',
    image: '../img/room-1.jpg',
    isPopular: true
  }
];
```
