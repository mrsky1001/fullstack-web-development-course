# Массив внутри объекта

В каждой комнате есть список удобств (Wi-Fi, Монитор, Кресло). Как сохранить список внутри объекта?
Конечно же, вложить массив внутри объекта! 

Значением свойства `equipment` будет массив строк: `['Wi-Fi', 'Монитор']`.

## 🛠 Задание

Добавьте свойство `equipment` в вашу первую комнату (между `description` и `image`). Не забывайте ставить запятые между свойствами объекта!

```js:start
const room = {
  description: 'Идеальное тихое пространство для индивидуальной работы, важных звонков и глубокой концентрации.',
  image: '../img/room-1.jpg',
};
```

```js:solution
const room = {
  description: 'Идеальное тихое пространство для индивидуальной работы, важных звонков и глубокой концентрации.',
  equipment: ['Wi-Fi 500 Мбит/с', '4K Монитор', 'Эргономичное кресло', 'Климат-контроль'],
  image: '../img/room-1.jpg',
};
```
