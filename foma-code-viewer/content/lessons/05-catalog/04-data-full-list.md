# Заполнение базы данных

Одна комната готова. Теперь нам нужно добавить остальные офисы. Так как это монотонная работа, мы подготовили полный список для вас. 

Обратите внимание на синтаксис: объекты внутри массива отделяются друг от друга запятыми. 

## 🛠 Задание

Скопируйте и замените ваш массив `OFFICE_ROOMS` полным списком из решения ниже. Потратьте минутку, чтобы изучить, какие данные там хранятся.

*(В этом же файле мы позже добавим массив фейковых бронирований `MOCK_BOOKINGS`, но пока ограничимся только комнатами).*

```js:start
// СмартОфис — База данных офисных комнат и бронирований
const OFFICE_ROOMS = [
  {
    id: 'focus-1',
    // ...
  }
];
```
