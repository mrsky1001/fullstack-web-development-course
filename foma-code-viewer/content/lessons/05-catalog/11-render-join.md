# Склеивание массива (join)

Если мы оставим код как есть, на экране между карточками появятся некрасивые запятые!

Вспомните: метод `.map()` возвращает **массив**. А браузеру при вставке в `innerHTML` нужна **сплошная текстовая строка**. При попытке вставить массив браузер автоматически преобразует его в строку, разделяя элементы запятыми.

## Решение
У массивов есть метод `.join('разделитель')`. Он берет все элементы и склеивает их в одну строку. Если в качестве разделителя передать пустую строку `''` (без пробела внутри), то карточки склеятся вплотную друг к другу без запятых!

## 🛠 Задание
Добавьте вызов `.join('')` сразу после закрывающей скобки метода `map()`.

```js:start
function renderCatalog() {
  container.innerHTML = OFFICE_ROOMS.map(room => `
    <div class="catalog-card">${room.name}</div>
  `);
}
```

```js:solution
function renderCatalog() {
  container.innerHTML = OFFICE_ROOMS.map(room => `
    <div class="catalog-card">${room.name}</div>
  `).join('');
}
```
