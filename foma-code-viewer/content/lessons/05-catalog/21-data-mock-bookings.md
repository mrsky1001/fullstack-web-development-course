# База данных бронирований

Мы закончили с функционалом Вебинара 5!
Но перед тем как завершить, нам нужно подготовить данные для будущих вебинаров (где мы будем делать Личный кабинет пользователя).

Нам понадобится еще один массив — список фейковых бронирований. 
В настоящих приложениях такие списки приходят с сервера (от бэкенд разработчика). Но у нас пока нет бэкенда, поэтому мы захардкодим их прямо в JS.

## 🛠 Задание
В файле `js/data.js` в самом низу добавьте массив `MOCK_BOOKINGS`. И на этом вебинар официально завершен!

```js:start
const OFFICE_ROOMS = [
  {
    image: '../img/room-6.jpg',
    isPopular: false
  }
];
```
