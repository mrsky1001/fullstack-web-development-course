# Вложенный маппинг для списка

Посмотрите на список удобств в нашей функции (`<ul class="card-equipment">`). Там жестко прописаны "Wi-Fi" и "Монитор". 

Но в наших данных `room.equipment` — это тоже массив! Значит, мы можем использовать метод `.map()` внутри метода `.map()`!

Мы пройдемся по массиву удобств `room.equipment`, обернем каждое удобство `item` в тег `<li>` и снова склеим их через `.join('')`.

## 🛠 Задание
Замените статичные теги `<li>` на вложенный вызов метода `map` внутри интерполяции. 

*(Теперь страница Каталога будет идеально работать и выводить все 6 комнат из базы!)*

```js:start
const equipmentHtml = `
  <ul class="card-equipment">
    <li>Wi-Fi</li>
    <li>Монитор</li>
  </ul>
`;
```

```js:solution
const equipmentHtml = `
  <ul class="card-equipment">
    ${room.equipment.map(item => `<li>${item}</li>`).join('')}
  </ul>
`;
```
