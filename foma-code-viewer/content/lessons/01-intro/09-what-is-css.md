# Что такое CSS?

Отлично! Мы закончили базовый "скелет" нашей страницы. HTML выполнил свою задачу — сообщил браузеру структуру текста. Но сейчас наша страница выглядит как документ из 90-х годов: черный текст на белом фоне, стандартный шрифт с засечками.

Здесь на сцену выходит **CSS** (Cascading Style Sheets — Каскадные таблицы стилей).

Если HTML — это кирпичи и бетон (структура), то CSS — это обои, краска, окна и дизайн. CSS берет наши сырые HTML-теги и превращает их в красивые элементы.

## Как работает CSS?

Код CSS пишется по строгим правилам (синтаксису). Нам нужно сказать браузеру **ЧТО** мы хотим изменить, и **КАК** мы хотим это изменить.

1. Сначала мы пишем **Селектор** (например, `h1`) — мы выбираем тег, который будем красить.
2. Затем открываем фигурные скобки `{ }`.
3. Внутри пишем **Свойство** (например, `color`) и через двоеточие его **Значение** (например, `red`). В конце обязательно ставится точка с запятой `;`.

В этом шаге нет задания. Просто переключитесь на вкладку **style.css** в редакторе (если она еще не активна) и посмотрите на структуру. Мы переходим к написанию стилей!

```html:start
<body>
  <h1>Привет, мир!</h1>
  <img src="https://placehold.co/150x50/007bff/FFF?text=SmartOffice" alt="Логотип СмартОфис">
  <p>Это мой первый сайт, и я только учусь веб-разработке.</p>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>
  <a href="https://ru.wikipedia.org/wiki/HTML">Узнать больше</a>
</body>
```

```css:start

```
