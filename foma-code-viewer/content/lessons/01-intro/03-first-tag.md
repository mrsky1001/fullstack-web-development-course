# Пишем первый тег <h1>

Пора переходить к практике! Самый главный элемент на любой странице — это её заголовок. 

Для создания главного заголовка используется тег `<h1>` (от английского *Heading 1* — заголовок первого уровня). 

Браузер видит этот тег и автоматически делает текст внутри него крупным и жирным, а также дает поисковым системам (Яндекс, Google) понять, о чем эта страница.

## Как это работает?
1. Пишем открывающий тег `<h1>`.
2. Внутри пишем сам текст заголовка.
3. Закрываем тег `</h1>`.

## 🛠 Задание

В редакторе справа напишите тег `<h1>`, а внутри него текст `Привет, мир!`. Обязательно закройте тег.

После того, как напишете, нажмите "Показать решение", чтобы проверить себя!

```html:start

```

```html:solution
<h1>Привет, мир!</h1>
```
