# Картинки <img>

Какой же современный сайт без картинок? Для вставки изображений используется тег `<img>` (от *Image*).

Это **одинарный тег**. У него нет закрывающей пары `</img>`, потому что внутрь картинки нельзя положить текст или другой тег. Он просто вставляет картинку сам по себе.

У тега `<img>` есть два важных атрибута:
1. `src` (Source — источник) — ссылка на саму картинку.
2. `alt` (Alternative — альтернативный текст) — текст, который покажется, если картинка не загрузится (например, при медленном интернете). Это важно для поисковиков и скринридеров (программ для слабовидящих).

Пример:
`<img src="https://example.com/cat.jpg" alt="Рыжий кот">`
