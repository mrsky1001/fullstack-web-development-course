# Базовая структура HTML-документа

До сих пор мы писали теги просто подряд. Наш редактор кода и современные браузеры достаточно умны, чтобы это отобразить.

Но по правилам стандарта, настоящий HTML-файл должен иметь строгую базовую структуру — "каркас". 

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Название вкладки</title>
  </head>
  <body>
    <!-- Здесь весь видимый контент -->
  </body>
</html>
```

## Разбор структуры:
1. `<!DOCTYPE html>` — Говорит браузеру, что это современный стандарт HTML5.
2. `<html>` — Самый главный тег, в него оборачивается вообще всё.
3. `<head>` — "Голова" сайта. Сюда пишутся настройки, которые **не видны на странице** (шрифты, кодировка, подключение стилей).
4. `<body>` — "Тело" сайта. Сюда пишется **всё, что видит пользователь** (то, что мы писали в прошлых шагах).

## 🛠 Задание

Оберните наш написанный код в тег `<body></body>`. На практике в настоящем проекте весь контент всегда должен лежать внутри `<body>`.
