# Абзацы текста <p>

Отлично, у нас есть заголовок! Но страница редко состоит из одного заголовка. Нам нужен обычный текст.

Для создания абзацев (параграфов) используется тег `<p>` (от английского *Paragraph*). 

Каждый тег `<p>` создает новый блок текста, автоматически добавляя небольшие отступы сверху и снизу, чтобы текст не слипался.

```html
<p>Это первый абзац текста.</p>
<p>А это уже второй абзац.</p>
```

## 🛠 Задание

Добавьте под вашим заголовком новый тег `<p>`. Внутри него напишите текст: `Это мой первый сайт, и я только учусь веб-разработке.`.

Обязательно убедитесь, что вы закрыли тег `</p>`.

```html:start
<h1>Привет, мир!</h1>

```

```html:solution
<h1>Привет, мир!</h1>
<p>Это мой первый сайт, и я только учусь веб-разработке.</p>
```
