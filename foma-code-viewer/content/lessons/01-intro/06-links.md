# Ссылки и атрибуты

Веб-страницы называются "Всемирной паутиной", потому что они связаны друг с другом ссылками. 

Ссылка создается с помощью тега `<a>` (от английского *Anchor* — якорь).

Но просто написать `<a>Кликни сюда</a>` недостаточно. Браузеру нужно знать, **куда именно** должна вести эта ссылка. Для этого используются **атрибуты**.

## Атрибуты тегов
Атрибуты — это дополнительные настройки тега. Они пишутся **внутри открывающего тега** через пробел после его имени.

У тега ссылки есть обязательный атрибут `href` (Hypertext Reference), в котором мы указываем адрес (URL) нужного сайта.

Пример:
`<a href="https://ya.ru">Перейти на Яндекс</a>`

Адрес в атрибуте `href`: `https://ru.wikipedia.org/wiki/HTML`.

```html:start
<h1>Привет, мир!</h1>
<p>Это мой первый сайт, и я только учусь веб-разработке.</p>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

```
