# Маркированные списки

Очень часто нам нужно перечислить какие-то элементы: особенности товара, пункты меню, преимущества компании. Для этого используются списки.

Список в HTML создается с помощью комбинации **двух разных тегов**. Это как коробка с вещами: сначала нужна коробка, а потом сами вещи.

1. `<ul>` (Unordered List) — это сама "коробка". Тег, который говорит: "Здесь начинается список с точечками (маркерами)".
2. `<li>` (List Item) — это "вещи в коробке". Пункты списка. Каждый пункт должен быть обернут в свой тег `<li>`.

```html
<ul>
  <li>Первый пункт</li>
  <li>Второй пункт</li>
</ul>
```
*Обратите внимание: теги `<li>` находятся **внутри** тегов `<ul>`. Это называется вложенностью тегов.*

## 🛠 Задание

Под вашим абзацем создайте список из трех технологий, которые мы изучаем:
1. Создайте теги `<ul></ul>`.
2. Внутри них создайте три пункта `<li>`.
3. Тексты пунктов: `HTML`, `CSS`, `JavaScript`.

```html:start
<h1>Привет, мир!</h1>
<p>Это мой первый сайт, и я только учусь веб-разработке.</p>

```

```html:solution
<h1>Привет, мир!</h1>
<p>Это мой первый сайт, и я только учусь веб-разработке.</p>
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```
