# CSS-селекторы

Чтобы изменить стиль элемента, мы должны сначала «дотянуться» до него. Для этого используются селекторы. Самый простой тип селектора — селектор по имени тега.

Если мы хотим раскрасить все абзацы `<p>` на странице, мы пишем:
```css
p {
  /* стили */
}
```

## 🛠 Задание

Давайте создадим пустые "коробочки" для стилей. В файле **style.css** создайте два селектора:
1. Селектор для тега `h1` с пустыми фигурными скобками `{}`.
2. Селектор для тега `body` с пустыми фигурными скобками `{}`.

*Подсказка: не забудьте, что после названия тега нужно поставить пробел, а затем открыть `{` и закрыть `}` фигурные скобки. Между правилами для разных тегов принято оставлять пустую строку для красоты.*

```html:start
<body>
  <h1>Привет, мир!</h1>
  <img src="https://placehold.co/150x50/007bff/FFF?text=SmartOffice" alt="Логотип СмартОфис">
  <p>Это мой первый сайт, и я только учусь веб-разработке.</p>
  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>
  <a href="https://ru.wikipedia.org/wiki/HTML">Узнать больше</a>
</body>
```
