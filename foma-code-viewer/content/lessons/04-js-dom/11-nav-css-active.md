# Активный пункт меню (CSS)

Вторая задача этого вебинара — сделать так, чтобы пользователь всегда понимал, на какой странице сайта он находится (Главная, Каталог, Бронирования и т.д.). Для этого мы будем подсвечивать ссылку в верхнем меню (шапке).

Сначала нам нужно добавить CSS-класс, который будет отвечать за эту подсветку. Мы назовем его `.active` и будем применять вместе с основным классом ссылки `.nav-link`.

## 🛠 Задание

Откройте файл `style.css`. Промотайте в самый низ и добавьте туда класс `.nav-link.active`. Мы сделаем текст синим, а фон — светло-голубым (`#eaf2ff`). 
*(Заметьте, что классы написаны слитно без пробела. Это значит "элемент, у которого есть ОБА этих класса одновременно").*

```css:start
.center-action {
  text-align: center;
  margin-top: 20px;
}

```

```css:solution
.center-action {
  text-align: center;
  margin-top: 20px;
}

.nav-link.active {
  color: #007bff;
  background-color: #eaf2ff;
}
```
