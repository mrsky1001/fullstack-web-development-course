# Поиск контейнера в DOM

Тосты (уведомления) не должны болтаться на странице где попало. Они должны появляться строго друг над другом в правом нижнем углу. Для этого нам нужна **обертка** (контейнер).

Проблема в том, что в нашем `index.html` этого контейнера нет! Мы будем создавать его прямо из JavaScript.

Но прежде чем создавать контейнер, мы должны проверить — а вдруг он уже был создан предыдущим тостом? Для этого мы воспользуемся мощным методом поиска элементов в DOM.

## document.getElementById
Этот метод позволяет найти любой элемент на странице по его атрибуту `id`. Мы будем искать элемент с ID `toastContainer`.
Результат поиска мы запишем в переменную `let container`. 
*Почему `let`, а не `const`? Потому что если контейнер не найдется, мы создадим его и перезапишем эту переменную!*
