# Функция инициализации навигации

Мы могли бы руками прописывать класс `.active` на каждой отдельной странице (на `index.html` повесить на "Главную", на `catalog.html` — на "Каталог"). Но это долго и неудобно при поддержке сайта.

Мы напишем умный JS-скрипт, который сам будет понимать, где находится пользователь, и подсвечивать нужную кнопку!

## 🛠 Задание

В файле `main.js` (под функцией `showNotification`) создайте новую пустую функцию `initNavigation`. И не забудьте вызвать её внутри нашего блока `DOMContentLoaded` в самом верху файла, чтобы она срабатывала при каждой загрузке страницы!

```js:start
// СмартОфис — Скрипт веб-приложения (Вебинар 4)
document.addEventListener('DOMContentLoaded', () => {
  
});
```

```js:solution
// СмартОфис — Скрипт веб-приложения (Вебинар 4)
document.addEventListener('DOMContentLoaded', () => {
  initNavigation();
});

// ... тут идет функция showNotification ...

}
```
