# Ждем загрузку DOM-дерева

Перейдем в файл `main.js`. 
Когда браузер читает HTML, он строит в оперативной памяти древовидную структуру всех элементов (заголовков, кнопок, картинок). Эта структура называется **DOM (Document Object Model)**. Именно через DOM наш JavaScript может управлять страницей.

Несмотря на то, что мы использовали `defer`, хорошей практикой является дополнительная страховка внутри самого скрипта. Мы должны сказать нашему коду: "Не делай ничего, пока браузер не подаст сигнал, что DOM полностью готов".

## События в JS
В JavaScript всё построено на **событиях**. Клик мыши — событие. Прокрутка — событие. Загрузка страницы — тоже событие.
Функция `document.addEventListener('имя_события', функция_реакции)` позволяет нам "слушать" эти события.

Мы будем слушать событие `DOMContentLoaded` (DOM контент загружен). Как только оно произойдет, запустится наша **стрелочная функция** `() => { ... }`.
