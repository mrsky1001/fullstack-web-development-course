# Таймер (setTimeout)

Если мы вызовем нашу функцию 5 раз, на экране появятся 5 зеленых плашек. Но они останутся там навсегда, перекрывая интерфейс! Уведомления должны исчезать сами.

Для этого в JavaScript есть замечательная встроенная функция — `setTimeout`. Она позволяет отложить выполнение какого-либо кода на определенное время.

## Синтаксис
```javascript
setTimeout(() => {
  // код, который выполнится в будущем
}, 3500); // время задержки в миллисекундах (3500 мс = 3.5 секунды)
```

Мы скажем браузеру: "Подожди 3.5 секунды, а потом запусти код удаления тоста".
