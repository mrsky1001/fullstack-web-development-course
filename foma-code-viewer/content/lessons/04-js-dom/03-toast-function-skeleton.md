# Скелет функции уведомлений

Первая фича, которую мы реализуем — это "Тосты" (Toasts). Это такие всплывающие подсказки в правом нижнем углу экрана (например, "Вы успешно вошли в систему" или "Комната забронирована").

Мы создадим **функцию**, которую сможем вызывать из любого места нашего кода.

## Аргументы функции
Наша функция `showNotification` будет принимать два параметра:
1. `message` — сам текст уведомления.
2. `type` — тип уведомления (успех, ошибка, инфо). Это нужно, чтобы переключать цвета тостов.

Заметьте, что мы пишем `type = 'success'`. Это называется **значение по умолчанию**. Если при вызове функции мы передадим только текст, JS автоматически подставит `type = 'success'`, и тост будет зеленым!
