# Удаление из памяти (Вложенный таймаут)

Мы сделали тост невидимым (opacity 0), но **он всё еще физически существует** в HTML-коде страницы! Если пользователь будет сидеть на сайте час и кликать по кнопкам, в контейнере скопятся сотни невидимых `<div>`. Это приведет к тормозам.

Элемент нужно удалять физически с помощью метода `.remove()`.

## Почему нужен второй таймаут?
Наша анимация растворения длится 0.3 секунды (300 мс). Если мы вызовем `.remove()` сразу, тост исчезнет мгновенно, и анимации мы не увидим!
Поэтому мы ставим еще один маленький `setTimeout` ровно на 300 мс ВНУТРИ нашего большого таймаута. Он дождется конца анимации и только потом "убьет" элемент.

## 🛠 Задание
Добавьте вызов `setTimeout(() => toast.remove(), 300);` сразу после изменения стилей. Наша система уведомлений полностью готова!

```js:start
  setTimeout(() => {
    toast.style.transition = 'opacity 0.3s ease, transform 0.3s ease';
    toast.style.opacity = '0';
    toast.style.transform = 'translateY(10px)';
    
  }, 3500);
}
```

```js:solution
  setTimeout(() => {
    toast.style.transition = 'opacity 0.3s ease, transform 0.3s ease';
    toast.style.opacity = '0';
    toast.style.transform = 'translateY(10px)';
    setTimeout(() => toast.remove(), 300);
  }, 3500);
}
```
