# Событие живого ввода (input)

Раньше (в формах) мы использовали событие `submit`. Но для живого поиска мы не хотим заставлять пользователя жать кнопку Enter!
Мы хотим, чтобы каталог фильтровался мгновенно, прямо во время печатания. 

Для этого существует событие `input`. Оно срабатывает каждый раз, когда содержимое поля ввода меняется (добавлена буква, удалена буква, текст вставлен из буфера).

## 🛠 Задание
Повесьте слушатель `input` на поисковое поле и передайте ему вашу функцию `applyFilter`. 

```js:start
  function applyFilter() {
    // ...
  }

```

```js:solution
  function applyFilter() {
    // ...
  }

  if (searchInput) searchInput.addEventListener('input', applyFilter);
```
