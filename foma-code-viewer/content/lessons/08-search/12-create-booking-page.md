# Создание новой страницы

Наши поиски и сортировки в Каталоге работают идеально! Вы восхитительны!
Теперь переходим ко второй части вебинара — Калькулятору стоимости.

Для начала, нам нужна новая страница. Создайте файл `pages/booking.html` (скопировав каркас из `login.html`, чтобы не писать заново шапку и подвал).
Внутри тега `<main>` мы создадим заголовок "Оформление бронирования".

## 🛠 Задание
Создайте новую страницу и вставьте в нее этот каркас.

*(Так как в редакторе открыто только 3 вкладки, считайте вкладку `html` вашей новой страницей `booking.html`)*.

```html:start
<!-- Очистите вкладку и вставьте код из решения -->
```

```html:solution
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Оформление бронирования</title>
  <link rel="stylesheet" href="../css/style.css">
  <script src="../js/data.js" defer></script>
  <script src="../js/main.js" defer></script>
</head>
<body>
  <!-- Шапка (Header) -->
  
  <main class="main">
    <div class="container">
      <h1 class="page-title">Оформление бронирования</h1>
      <p class="page-subtitle">Заполните детали ниже для подтверждения бронирования</p>

      <div class="form-card">
        <!-- Сюда вставим форму -->
      </div>
    </div>
  </main>
  
  <!-- Подвал (Footer) -->
</body>
</html>
```
