# Страница "Мои бронирования"

Сразу создадим еще одну страницу — `pages/my-bookings.html`. 
На нее мы будем отправлять пользователя после того, как он успешно оформит бронь на предыдущей странице.

Пока что эта страница будет почти пустой. На ней будет только заголовок и контейнер `<div id="myBookingsList"></div>`. Мы заполним его данными в финальном Вебинаре 9!

## 🛠 Задание
Представьте, что вы создали файл `my-bookings.html` в вашем проекте и скопировали туда стандартный HTML каркас.
Идем дальше! Ничего вписывать не нужно.

```html:start
<section class="my-bookings">
  <div class="container">
    <h2>Мои бронирования</h2>
    <!-- Добавьте контейнер myBookingsList -->
  </div>
</section>
```

```html:solution
<section class="my-bookings">
  <div class="container">
    <h2>Мои бронирования</h2>
    <div id="myBookingsList"></div>
  </div>
</section>
```
