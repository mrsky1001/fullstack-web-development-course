# Обработка текста из поиска

Мы подготовили функцию отрисовки `render(rooms)`. Теперь нам нужна функция `applyFilter()`, которая будет запускаться каждый раз, когда пользователь печатает букву в поиске.

Первое, что должна сделать функция — получить текст из поля ввода `searchInput.value`.
Но есть проблема: JavaScript чувствителен к регистру ("Фокус" и "фокус" — это разные слова). Чтобы поиск работал идеально, мы переведем введенный текст в нижний регистр с помощью метода строк `.toLowerCase()`.

## 🛠 Задание
Создайте функцию `applyFilter()` после функции `render()`. Сразу получите поисковой запрос `q`.

```js:start
  function render(rooms) {
    // ... логика рендера ...
  }

```

```js:solution
  function render(rooms) {
    // ... логика рендера ...
  }

  function applyFilter() {
    const q = (searchInput ? searchInput.value : '').toLowerCase().trim();
  }
```
