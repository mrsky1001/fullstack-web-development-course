# Позиционирование слайдов

Нам нужно, чтобы все 4 слайда находились точно в одном и том же месте, один под другим. 
Для этого мы "отрываем" их от обычного потока документа с помощью `position: absolute;` и растягиваем на весь контейнер (`top: 0`, `left: 0`, `width: 100%`, `height: 100%`).

Чтобы картинки внутри слайда не сплющивались, мы применим изученное ранее свойство `object-fit: cover;`.

Также мы делаем ВСЕ слайды по умолчанию невидимыми через `opacity: 0;` (прозрачность 0). И задаем плавность исчезновения через `transition: opacity 0.3s;`.

## 🛠 Задание
Добавьте эти стили для слайдов в CSS. Сейчас слайдер полностью исчезнет с экрана — это нормально, ведь мы скрыли все слайды!

```css:start
.slider {
  /* ... стили ... */
}
```

```css:solution
.slider {
  /* ... стили ... */
}

.slide {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  opacity: 0;
  transition: opacity 0.3s;
}

.slide-img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center;
}
```
