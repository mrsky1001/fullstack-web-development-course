# Перезапуск при клике (Кнопки)

Представьте ситуацию: пользователь смотрит на картинку уже 2.5 секунды. И тут он решает вручную нажать кнопку "Вперед". Слайд переключается. Но через 0.5 секунды срабатывает наш авто-таймер и переключает слайд еще раз! Получится дерганье.

Чтобы этого избежать, каждый раз, когда пользователь САМ нажимает на кнопки, мы должны перезапускать таймер заново (сбросить 3 секунды). Для этого просто вызовем `startAuto()` внутри кликов!

## 🛠 Задание
Допишите `startAuto();` в ваши обработчики кликов по кнопкам (внутри фигурных скобок после точки с запятой).

```js:start
  if (nextBtn) nextBtn.addEventListener('click', () => { next(); });
  if (prevBtn) prevBtn.addEventListener('click', () => { prev(); });
```

```js:solution
  if (nextBtn) nextBtn.addEventListener('click', () => { next(); startAuto(); });
  if (prevBtn) prevBtn.addEventListener('click', () => { prev(); startAuto(); });
```
