# Заглушка пустого списка

Если пользователь только что зарегистрировался, у него еще нет заявок. Оставлять просто пустой экран — это плохой UX (пользовательский опыт). Человек может подумать, что страница зависла или не загрузилась.

Мы нарисуем красивую заглушку `.empty-message` с пунктирной рамкой (`border: 1px dashed #dddddd`), внутри которой выведем ободряющий текст.

## 🛠 Задание
Добавьте стиль для пустого сообщения. Это последние CSS-строчки в этом проекте!

```css:start
.booking-item {
  /* ... */
}
```

```css:solution
.booking-item {
  /* ... */
}

.empty-message {
  text-align: center;
  padding: 30px;
  color: #666666;
  border: 1px dashed #dddddd;
  border-radius: 6px;
  max-width: 600px;
  margin: 30px auto 0 auto;
}
```
