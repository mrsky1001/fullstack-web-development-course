# Сохранение сессии (localStorage)

Если логин и пароль совпали, нам нужно "запомнить", что этот пользователь вошел в систему. Иначе, перейдя на соседнюю страницу, браузер снова "забудет" его.

Для этого в браузере есть встроенная база данных **`localStorage`** (локальное хранилище). Данные там сохраняются даже после закрытия вкладки! 

Мы запишем логин пользователя в `localStorage` под ключом `currentUser`. Наша функция `updateAuthNav()` (из Вебинара 4) уже умеет читать этот ключ и менять кнопку "Войти" на "Выйти"!
