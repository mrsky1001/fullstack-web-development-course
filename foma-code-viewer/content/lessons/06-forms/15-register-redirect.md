# Очистка формы и редирект

После того как пользователь успешно зарегистрировался, нужно сделать две вещи:
1. Очистить все поля ввода. У форм есть специальный метод `form.reset()`.
2. Отправить пользователя на страницу входа. 

Мы сделаем это через небольшую паузу (1200 миллисекунд = 1.2 секунды), чтобы пользователь успел прочитать зеленое всплывающее уведомление об успехе. 
Для создания паузы используется `setTimeout(функция, время)`. А для перенаправления (редиректа) на другую страницу — `window.location.href = 'ссылка'`.

## 🛠 Задание
Добавьте логику сброса и редиректа внутрь блока `if (isValid)`. Функция регистрации полностью готова!

```js:start
    if (isValid) {
      showNotification('Пользователь зарегистрирован успешно!', 'success');
      
    }
```

```js:solution
    if (isValid) {
      showNotification('Пользователь зарегистрирован успешно!', 'success');
      form.reset();
      setTimeout(() => {
        window.location.href = 'login.html';
      }, 1200);
    }
```
