## 📖 О курсе

Этот репозиторий представляет собой **полноценный образовательный курс** по изучению основ веб-разработки. Курс разработан для **абсолютных новичков** и первокурсников, не имеющих предыдущего опыта программирования.

### 🎯 Цели курса

После прохождения курса вы сможете:

- ✅ Создавать структурированные **HTML5** документы с семантической разметкой
- ✅ Стилизовать страницы с помощью **CSS3** (Flexbox, Grid, адаптивность)
- ✅ Писать интерактивные скрипты на **Vanilla JavaScript**
- ✅ Работать с **DOM**, **событиями** и **локальным хранилищем**
- ✅ Собрать **портфолио из 6 готовых проектов**

## 📁 Структура каждого урока

```
lesson-name/
│
├── README.md              # Теоретический материал урока
│
├── examples/              # Готовые примеры кода
│   ├── 01-example/
│   │   ├── index.html     # HTML-структура
│   │   ├── style.css      # Стили (если есть)
│   │   └── script.js      # JavaScript (если есть)
│   └── 02-example/
│       └── ...
│
├── practice/              # Практические задания
│   └── 01-task/
│       └── task.md        # Описание задания
│
└── assets/                # Вспомогательные материалы
    ├── images/
    └── data/
```

### 📝 Формат файлов

| Файл | Содержимое |
|------|------------|
| `README.md` | Теория, синтаксис, таблицы, диаграммы |
| `examples/*/` | Рабочие примеры с подробными комментариями |
| `practice/*/task.md` | Задания с требованиями и критериями |
| `script.js` | Код вынесен в отдельные файлы (не inline) |

## 🚀 Как начать

### Шаг 1: Клонируйте репозиторий

```bash
git clone https://github.com/mrsky1001/fullstack-web-development-course.git
cd fullstack-web-development-course/4. 03. store-app/frontend/1.\ html-css-js
```

### Шаг 2: Установите VS Code

Скачайте и установите [Visual Studio Code](https://code.visualstudio.com/).

### Шаг 3: Установите расширения

| Расширение | Назначение |
|------------|------------|
| **Live Server** | Локальный сервер с автообновлением |
| **Prettier** | Автоформатирование кода |
| **Auto Rename Tag** | Автопереименование парных тегов |
| **Auto Close Tag** | Автозакрытие тегов |

### Шаг 4: Начните с Модуля 00

Откройте папку `00-environment-setup` и следуйте инструкциям.

### Шаг 5: Проходите последовательно

Каждый урок строится на предыдущих знаниях. Рекомендуется проходить курс **по порядку**.

## 📜 Принципы курса

### 🧹 Чистый код

Весь код следует лучшим практикам:
- Понятные имена переменных и функций
- Правильная структура и отступы
- Логическое разделение на файлы

### 🍦 Только Vanilla

Никаких фреймворков — только чистые технологии:
- HTML5
- CSS3
- JavaScript (ES6+)

### 💬 Подробные комментарии

Каждый файл содержит комментарии на **русском языке**, объясняющие:
- **Что** делает код
- **Почему** именно так
- **Как** это работает

### 🎯 Практико-ориентированность

- После каждого урока — практические задания
- В конце курса — 6 полноценных проектов
- Все примеры можно запустить в браузере
