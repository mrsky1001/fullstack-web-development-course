# Workspace Rules & Guidelines

## 1. Презентации и слайды (Webinar Presentations)
Полный свод правил оформления и генерации презентаций находится в файле [.agents/rules/presentation-design.md](file:///d:/IEEU%20International%20East-European%20University/fullstack-web-development-course/.agents/rules/presentation-design.md).

### Ключевые правила:
1. ❌ **НЕ ТРОГАТЬ МАКЕТЫ И ШАБЛОН СЛАЙДОВ (`slide_layouts`, `slide_master`):**
   - Макет / мастер-шаблон слайдов **СТРОГО НЕПРИКОСНОВЕНЕН**.
   - **Причина:** В макете шаблона автоматически генерируются номера слайдов и служебные элементы.
   - Запрещено модифицировать элементы внутри `prs.slide_layouts` (например, `for layout in prs.slide_layouts: ...`) или `prs.slide_masters`.
   - Макет используется исключительно для инстанцирования нового слайда (`prs.slides.add_slide(blank_layout)`). Все элементы добавляются только на уровне конкретного слайда (`slide.shapes`).
2. ❌ **НЕПРИКОСНОВЕННОСТЬ 1-ГО, 2-ГО И ПОСЛЕДНИХ СЛАЙДОВ:**
   - Слайд 1 (титульный): не трогать вообще.
   - Слайд 2 (план): менять только текст в списке и заголовок справа вверху.
   - Слайды «РЕЗУЛЬТАТ» и «ДО ВСТРЕЧИ!»: не трогать вообще.
3. ❌ **АУДИТОРИЯ:**
   - Категорически запрещено использовать слово «школьники». Аудитория — **студенты** (после 9 класса / колледж / СПО).
4. ❌ **НИКАКИХ ТЕНЕЙ:**
   - Удалять `<p:style>` и `<a:outerShdw>` у всех создаваемых фигур.
5. 🎨 **ПОЛНОЦЕННАЯ ТОКЕНИЗИРОВАННАЯ ПОДСВЕТКА СИНТАКСИСА КОДА (HTML, CSS, JS):**
   - Никаких серых строк кода и фейковых комментариев!
   - Запрещено использовать `CODE_COMM` для исполняемого кода (CSS-свойства, селекторы, команды JS).
   - В CSS свойства (`border-top`, `display`) строго `CODE_PROP` (#A78BFA), значения (`flex`, `solid`, `20px`) строго `CODE_VAL` (#4ADE80), цвета HEX (`#007bff`) `CODE_STR` (#FCD34D), селекторы `CODE_KW` (#38BDF8).
   - В HTML теги строго `CODE_TAG` (#F472B6), атрибуты `CODE_PROP` (#A78BFA), значения в кавычках `CODE_STR` (#FCD34D), а внутренний текст строго `CODE_TEXT` (#FFFFFF/#DDDDDD). Запрещено объединять текст с закрывающим тегом в `CODE_TAG`.
   - На смешанных слайдах (HTML + CSS) каждая строка должна быть независимо токенизирована по своему синтаксису.
